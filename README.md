# 银行回单工作台

> 0.1.61 · Windows x64 · 本地回单分割、交易对手核对与 PDF 导出

把银行 PDF 分割为单张回单，核对并批量修正交易对手，再按组或合并导出 PDF 和核对表。PDF、账户档案、读取规则和结果在本机处理，原件只读。

[使用指南](docs/usage.md) · [交易对手整理](docs/counterparty-grouping.md) · [开发与构建](docs/development.md) · [版本说明](docs/release-0.1.61.md)

## 安装与升级

当前提供 **Core x64** 安装包：`银行回单工作台_0.1.61_core_x64-setup.exe`。开发者：蚊子。

适用于 Windows 10/11 x64。关闭应用后安装，沿用原安装目录即可升级。程序自带私有 Python 运行时，不需要用户另装 Python。Core 处理带文字层、可以选中和复制文字的 PDF，不包含 OCR 运行时。安装包未签名；文件来源、版本和 SHA-256 请与交付清单核对。

**本方账户 Excel 导入模板已内嵌程序。** 只传安装包即可，在“选择本机档案 → 批量导入账户档案”下载模板，通过 Windows 另存为保存；安装目录无需额外放置 Excel 文件。

## 操作顺序

1. **导入并配置本方资料。** 选择 PDF，默认“分割全部回单”。需要分组时启用“按交易对手整理”，默认进入“选择本机档案”，选择公司、来源银行和完整本方账号，也可仅填写本批资料。每批对应一个本方账户。清除或更换来源后重新选择账户。
2. **分析并检查分割。** 查看原页和片段总览，处理待复核边界、特殊凭证及需要排除的片段。可微调边界、统一栏位高度，并保存已核对的版式模板。
3. **核对交易对手。** 进入分组后提取字段。“对方名称为空”和“对手待确认”分开处理；查看原件后可给单张或最多 200 张回单统一输入名称、选择已有名称，或确认原件确实没有名称，无需选择收付款方向。
4. **检查并导出。** 选择“每组一个 PDF”或“合并为一个PDF”，系统记住上次方式。两种方式均附总核对表，JSON 按需选择。导出显示阶段、阶段进度和已用时间；完成后核对目录、文件数及页数。

未启用分组时仍可直接分割并导出；只需要特定回单时可按关键词“查找提取回单”。输出写入新的独立目录，不覆盖既有结果。

## 常用能力

- 原页总览、片段总览、单张放大，以及可调整宽度的核对工作区。
- 按来源、凭证类型和审核状态筛选，批量确认、排除与恢复。
- 本机账户档案及 Excel 批量导入：完整预览有效、重复和错误行，保留长账号及前导零，只新增有效档案。
- 交易对手、内部往来、空白名称和待确认项分开查看；已自动识别的结果也可批量修正。
- 提前导出 Excel 核对草稿；正式导出附来源页码、栏位、分组、输出文件及页码映射。
- 同版式批量识别：框选本方及对手名称位置，试读和审核后应用；可保存本机规则供下一批同版式复用，保存的是位置，不是本次名称。
- 导出进度、错误提示和可恢复结果；PDF 写入等无法精确计数的阶段显示活动状态，不使用虚假百分比。

版式模板保存裁剪边界，读取规则保存字段位置，账户档案保存本方资料。停用档案或规则只影响今后的选择或自动匹配，不改已开始任务的资料快照。

## 本地处理与反馈

应用不自动上传 PDF、日志、账户资料或反馈，不提供自动更新服务。安装器可能提示安装或修复 Microsoft WebView2 Runtime；这是微软组件，具有独立更新行为。

“帮助与反馈 → 使用反馈”支持预览、复制、保存 TXT，以及用户主动选择的邮件、微信联系方式。**GitHub 公开反馈入口已移除。** 对外发送前请去除客户名称、账号、文件名和路径；应用不会替用户发送消息。

原件、数据库、日志、输出和本机验收材料不应提交到仓库。源码测试使用合成输入。

## 限制

默认限制为单 PDF 5,000 页、500 MiB，一次选择 500 个 PDF。速度受电脑、磁盘、字体图片与分组数量影响，不能只按页数估算。大批量处理请等待进度完成，不要在处理中移动原件或关闭应用。

识别结果需要抽查；陌生版式、缺失字段、来源不一致等保留核对提示。本工具不生成记账凭证，不代替账务判断，也不承诺识别结果无需审核。验证范围见[版本说明](docs/release-0.1.61.md)。

## 开发与维护

技术栈：Tauri 2、React、TypeScript、Rust、Python / PyMuPDF。前端使用 Bun。环境、测试和打包命令见[开发指南](docs/development.md)，交付检查见[发布清单](docs/release-checklist.md)。

- `src/`：界面和领域逻辑。
- `src-tauri/`：桌面宿主、文件操作与引擎通信。
- `engine/`：PDF 分析、提取、审核与导出。
- `tests/`：合成输入回归测试。
- `scripts/`：运行时、隐私审查和打包脚本。
