# 0.1.41 远端 GUI 验收记录（2026-09-22）

本记录保存本轮 0.1.41 Core x64 远端 Windows 现场的逐步人工验收结果。本轮现场操作已完成；以下只记录远端 GUI 实际观察，不把源码检查、自动化测试、安装包资源检查或此前版本结论写成现场通过。

## 记录边界

- 本轮现场帮助页已核对为 `v0.1.41`。此前安装步骤已通过；本轮只核对版本，不宣称重新安装通过。
- 现场入口观察为：没有“历史任务”入口，有“我的模板”入口。该观察只覆盖现场可见入口，不推断历史数据是否已逐项核验。
- 现场使用用户预先提供的 PDF 副本；按只读导入处理，不修改原件。本记录不写入真实业务路径、正文、账号或客户名称。
- GUI 截图仅可通过本次工具会话追溯，未另存图片文件；本记录不伪造截图文件路径。
- 现场计时以工具返回的 `Date.now()` 结果为准；UU 界面时钟与远端系统时钟可能不同，二者不混用。尚未取得 `Date.now()` 数值的步骤不填写精确耗时。
- 本记录只覆盖本次剩余六步定向检查，不自动扩展到旧版 M01–M35，也不把未操作项目标为通过。
- 本轮没有修改源码、重新打包或执行原件前后 SHA-256 核验；这些事项不替代远端 GUI 验收。

现场“我的模板”中可用的两个模板及已见参数如下。参数来自现场界面观察，后续如有逐项复核结果再补充状态；当前不据此宣称整套模板验收通过。

| 模板 | 现场已见参数 | 现场状态 |
| --- | --- | --- |
| HX-3栏回单模板 v6→v7 | v6 曾为三栏已核对 `3/3`；纸张 `209.90 × 297.04 mm`；top `1.47 / 99.80 / 198.48 mm`；v7 的 left `0`、width `209.90 mm`、height 全部 `97.40 mm` | v6 停用发生在创建 v7 之前；合法显式保存后 v7 可用 |

点击 HX-3 栏回单模板 v6 后，标题、图像和表格变为 HX 数据，但名称输入框仍显示 `3栏回单模板`。约 14 秒刷新后，名称输入框仍未改变；这是首次切换观察，此前 partial 保存路径另有记录且失败。本记录只记界面现象，不预判代码根因。

分析区已切换为“改为自动匹配”。随后导入 HX-C（华夏 202601，251 页），未输入关键词并开始分析。

后续现场观察到：HX-C 自动匹配、全部分割已载入结果 `738/738`。开始分析后约 80 秒的第一次观察已完成，因此这里只记录完成观察时的时间上界 `≤80 秒`，不将其写成精确耗时。结果页和微调阶段均隐藏“我的模板”入口。查看待复核后点击“批量确认同位置 251 处”只出现说明：“确认当前文件、相同页面尺寸的第 1 栏待复核片段共 251 处，每处保留自己边界”；没有显示具体风险原因，随后已取消，未点击“已检查确认”。

进入“调整所选边界”后，三栏现场参数为：第 1 栏 top `1.47 mm`、height `97.49 mm`；第 2、3 栏 top `99.8 mm`、`198.48 mm`，height 均为 `97.49 mm`，对应 HX-3 栏回单模板 v6。原始结果截图中的框位与模板参数近似，但仅凭编辑器画面不宣称逐页所有位置已核验。取消统一高度后，只将第 1 栏 height 从 `97.49 mm` 改为 `97.40 mm`，top 保持不变，第 2、3 栏保留原值，随后进入确认预览。

模板详情中现场 GUI 没有银行/凭证类型可视字段值。名称输入框在模板切换后仍不更新的现象已确认；本记录只记界面观察，不据此推断代码根因。

HX-C 预览随后完成，界面显示 `251` 处变化，风险分组为 `738`。该分组说明包含未变化栏位、图形或印章越界，以及第 2/3 栏重复风险合并 ×2；这些是界面风险分组信息，不等同于 738 处均为真实业务变化。抽查尾页时，251 页实际为两栏，第一栏框位在第一张回单内，没有伸入第二张。

随后选择“保存为版式模板”：名称默认显示 `3栏回单模板`，手动填写为 `HX-3栏回单模板`；界面显示已核对 `738/738` 后点击“保存本轮 251 处”。约 90 秒后，界面显示本轮 `251` 处已保存、候选 `738`、待复核 `487`，并以红字提示：“本轮审核已保存，但版式模板未保存成功。可以重试保存模板。”点击“重试保存模板”一次，约 33 秒后仍为相同失败提示，未继续重复点击。随后依次“完成微调，返回结果”→“返回分析”→“我的模板”查看：`HX-3栏回单模板 v6` 仍在，第一栏 height 仍为 `97.49 mm`，没有生成新版本；另一模板 `3栏回单模板 v2` 仍在。边界 `251` 处已保存不等于版式模板保存成功。本次批量确认与保存操作仅用于测试副本流程验证，不作为全部 `738` 处真实业务审核。

收尾后已手选 `HX-3栏回单模板 v6`，并将来源 PDF 替换为 SH-A（26 页）。不输入关键词时，右侧仍明确显示 HX v6，随后开始分析。结果为 `73` 候选、`1` 待复核，并出现“查看特殊单证 2 页”。跨银行与特殊单证隔离在本次样本上通过，但不泛化为所有样本均通过。

SH-A 第 18 页贷款利息到期通知书仅有 1 个候选，绿框覆盖整页；第 26 页电子缴税付款凭证有 2 个候选，逐一点击绿框时分别覆盖上下两张凭证，未见 HX 三栏边界误套。第 25 页普通回单的第一栏进入微调后显示只读参数 top `2.47 mm`、height `93 mm`，不同于 HX v6 的 top `1.47 mm`、height `97.49 mm`；本次范围为 1 个 PDF、1 页、3 处，未改参数即返回。

另见一个审核状态疑点：第 18 页和第 26 页的 3 个特殊单证候选在本轮尚未确认，却显示为“已确认”。这只记录为既有审核恢复/状态继承疑点，不能据此称本轮重新计算审核通过。

随后在“我的模板”选择 `HX-3栏回单模板 v6`，点击“停用此版式”后自动返回分析；手选模板已清除，界面显示为“自动匹配”。重新进入“我的模板”并勾选“显示已停用模板”后，HX v6 显示为已停用，`3/3` 已核对和旧坐标仍保留；“选用此模板”和“停用此版式”按钮均禁用，未见恢复启用入口。另一 `3栏回单模板 v2` 仍可用。

另一次重开管理器时自动选中 `generic v2`，名称输入框为空并出现“请输入 1 至 256 字符”提示；切换到已停用 HX v6 后名称显示正确。该现象作为已有名称框不同步问题的补充观察记录。

停用 HX v6 后，自动模式导入 HX-B（111 页）并执行全部分割，结果为 `327/0`；列表中可见候选均显示“已确认”，本轮没有点击审核确认。进入调整页面后只读观察到三栏 top `1.47 / 99.8 / 198.48 mm`、height 均 `97.49 mm`，范围为 1 个 PDF、108 页、324 处命中；未修改参数，点击返回后停在结果页。该段是创建 v7 前的历史观察；HX-B 已有来源校准与审核记录，不能仅凭参数相同认定停用失败，也不能以它单独证明未回落旧版本。

随后在 HX-B 上保持三栏统一高度为 true，只将三栏 height 从 `97.49 mm` 改为 `97.40 mm`，范围为 1 个 PDF、108 页、324 处。预览显示 `324` 处变化、`324` 个核对组；在测试副本中全部标为已核对 `324/324`，勾选保存模板并将默认名称改为 `HX-3栏回单模板`。保存后显示 `324` 处已保存，且版式模板 `HX-3栏回单模板` 已保存，可供同版式新文件参考。返回管理器后，模板由 v6 递增为 v7 并可用，`3/3` 已核对；v7 参数为 top `1.47 / 99.80 / 198.48 mm`、left `0`、width `209.90 mm`、height 全部 `97.40 mm`、纸张 `209.90 × 297.04 mm`。另一模板 v2 未变，此次名称显示正确。

该合法三栏整体更新路径通过；此前 partial 路径的失败提示只属于此前操作路径，不能泛化为更新功能整体失败。v6 的停用发生在创建 v7 之前，本次 v7 来自显式保存，不视为旧版自动回落。当前远端保留 HX v7 可用，未再次停用；本轮仍未做逐页业务审核。
