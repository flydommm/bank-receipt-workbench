# 0.1.38 大任务管理路径优化证据

本记录区分本机基准、正确性回归和远端 GUI。以下数字是本机测量，不是干净 Windows 的承诺耗时；远端验收另记于 `manual-test-0.1.38.md`。

## 已定位的重复工作

每读取一批最多 200 条审核结果，旧路径都重新构造并验证整份页面检查点和候选快照，再重复验证审核清单及历史记录。分页还会对不断增长的条目列表反复序列化。合成 671 页、2013 个候选的单批读取 cProfile 记录约 1.49 亿次调用，其中整份快照重建占据主要耗时。源 PDF 核验在该次本机样本中约 0.04 秒，未移除这项检查。

## 修改及边界

- 同一读事务内，对所有相关数据库原始行、结构与绑定计算 SHA-256 指纹；仅完全相同的已验证内容可复用审计结果。记录、检查点、数据库结构、来源绑定和版本变化均重新验证。
- 缓存存取深拷贝；两类缓存各最多 4 条、32 MiB 序列化 JSON。该数值不是进程实际内存的硬上限。
- 每次请求仍读取源 PDF 实际内容并核对 SHA-256、页数、大小和任务绑定，不以文件时间或大小替代哈希。
- 分页条目只计算一次序列化大小，完整响应仍通过字节、节点、深度和游标校验。
- 审核分页使用已有只读常驻 Python 服务。写入、校准、导出继续走原来的受控路径；冷启动第一批仍需完整审计。

## HX-A 空白候选回归

历史边界擦到上一张印章图片的纯白外框时，旧逻辑保留空白候选。现在只在完整原生证据、无文字且只与跨界图片相交的槽内执行有界空白证明。依据图片原生有效分辨率渲染相交区域并保留源像素边缘；只有严格纯白才排除。图片信息不足、扫描或不完整证据、非轴对齐变换、超出每页 200 万像素预算及渲染异常均保留候选。

HX-A 全 671 页对照：自动边界 1974 处，历史边界旧逻辑 1993 处，历史边界新逻辑 1974 处。排除的是 19 个单张尾页上的空白第二栏；第 669 页仍为三栏，第 671 页仍为双栏。最终实现对所有影响页及关联页复测，新增检查 19 次累计 0.014568 秒。加工使用独立副本，源文件大小与 SHA-256 前后一致；真实文件及业务内容未进入仓库。

独立审查发现并推动修复了固定低分辨率可能吞掉极淡像素的问题；新增回归先失败后通过。审查再用不同源图分辨率、非整数位置和缩放、插值开关等 212 个纯内存组合检查极淡像素，未出现候选误排除。
