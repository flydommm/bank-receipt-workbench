# 导出后直接移除来源复测

适用范围：包含“导出后直接移除来源”修复的 0.1.30 Core x64 重打包版本。原 0.1.30 包（提交 `de03f49ce74c`）不含此改动；安装时请按新包所在目录及 `build-info.json` 的源码提交区分，版本号相同。

## 正常流程

1. 从独立工作副本导入银行回单 PDF，记录原件大小和 SHA-256。
2. 输入关键词，完成分析，进入“选择导出范围”，点击“生成预览（N 处）”。
3. 点击“选择目录并导出”，将结果写入新的结果目录。
4. 导出成功后，确认底部直接出现“移除本次来源”，无需先返回审核或分析。
5. 点击“移除本次来源”，应立即回到分析页，当前来源列表及旧候选预览清空。
6. 导入另一家银行的 PDF，修改关键词后分析；应显示新文件的结果，不残留前一银行的名称、片段数量或候选。
7. 检查刚导出的 PDF 仍可打开；原始 PDF 的大小、SHA-256 不变。此操作不应执行历史任务删除。

## 取消、失败和重复操作

- [ ] 仅生成预览、尚未实际导出时，没有“移除本次来源”。
- [ ] 取消输出目录选择后仍保留当前来源和预览，可以再次导出。
- [ ] 目录选择器或导出失败后显示错误，保留来源，可以重试；此时不出现成功后的移除按钮。
- [ ] 打开目录选择器及导出进行中，返回审核和重新选择范围不可操作，不能重复启动导出。
- [ ] 导出成功不会自动移除来源，需用户主动点击。
- [ ] 成功后点击“重新选择范围”并生成新预览，重新显示“选择目录并导出”，不残留上一轮的移除按钮。
- [ ] 多 PDF 一批导出后，“移除本次来源”移除的是当前整批来源；磁盘上的 PDF 和已导出文件保留。
- [ ] 在常用窗口大小和 DPI 下，成功提示与移除按钮可见，Tab/Enter 可操作。
