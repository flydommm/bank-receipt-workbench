# 引导式微调与审核流程（旧版机制参考）

本文保留早期版本按银行、版式和位置分轮的微调机制，供维护时参考。下文的“进入微调”“完成本银行，进入下一银行”等按钮、轮次安排和恢复说明属于旧版实现，不作为 0.1.57 的操作指引，也不代表当前“帮助与反馈”的逐项内容。

当前操作请看[使用指南](usage.md#微调边界)。0.1.57 没有“历史任务”入口；在总览中通过“调整所选边界”进入微调，核对并保存后返回结果，完成审核后通过“导出回单”进入导出设置并直接选择目录导出。

## 使用顺序

应用完成“导入 PDF → 选择处理方式 → 开始回单分析”后，先在“检查与处理”中查看片段总览、原页总览和绿色候选框。正常路径是：检查自动结果 → 处理待复核片段 → 点击“导出回单”进入导出设置 → 选择目录并导出。自动边界正确时直接走这条路径，不需要进入微调。

如果发现候选边界不完整、带入相邻回单或整页与同版式回单不协调，先在结果页选中需要调整的命中片段，再点击“进入微调”。默认准备待复核片段和当前选中的片段；主动选择尚未人工修改的自动确认片段时，还会核实其同银行、同版式、同位置的自动候选，供本轮同步。其他已确认位置不需要重新审核。准备阶段会保留当前选中的出具银行、位置和样本，随后按下面的顺序处理：

1. 系统从进入前选中的银行、版式和位置安排本轮，例如首栏、中间栏、末栏或单张尾页，并沿用该片段作为当前样本；该银行的剩余位置完成后再进入其他银行。
2. 本轮范围由系统自动限定为同一银行、同一回单版式和同一位置的候选。同类范围只接受已核实的同一出具银行、同一回单版式和同一位置；同一家银行的多个 PDF 仍合并为一个来源，不会改变来源边界。
3. 拖动绿色候选框、拖动手柄调整大小，或使用方向键微调。连续操作只更新当前轮临时调整，不会在第一次松开鼠标后自动检查、保存或进入下一步。
4. 检查样本的回单抬头、交易内容、印章和底部末行，全部调整完成后点击“确认并预览本轮 N 处”。没有需要移动的框，也要点击这个按钮生成本轮预览；这一步不会写入审核结果。
5. 预览成功后，审核区会显示“本轮预览 N 处，尚未保存”。在右侧逐项查看本轮候选，发现边界不合适时点击“返回调整”，修改样本后重新预览；检查无误后确认“保存后记住本版式框位置，供下次同版式文件参考”是否符合本次意图，再点击“保存本轮 N 处”。默认记住稳定的版式几何参考；取消勾选仍会保存本轮裁剪和确认，但不会新增版式参考。数字以当前轮实际范围为准。
6. 保存成功会同时完成本轮确认，审核区显示“第 1 轮已保存并确认”，不需要再点击第二个确认按钮。本次范围内还有未完成位置时，点击“开始下一位置微调”。如果显示“本次范围内还剩 0 处”，但你还想调整该银行的首栏或中间栏，点击“继续微调本银行其他位置”，选择位置后点击“开始所选位置微调”。系统只在你选定后把该组纳入新一轮，之前确认的片段继续保留；取消位置选择会回到已完成的本轮。
7. 本次微调范围内当前银行的位置都确认后，先点击“检查本银行完成情况”，再点击“完成本银行，进入下一银行”。最后一个银行检查完成后点击“完成本次微调”。银行进度同时显示本次范围内还剩多少处；若某轮只保存 1 处、还剩 7 处，应点击“开始下一位置微调”继续，不能把退出当作全部确认。如果要改选其他片段，先取消尚未保存的调整（如有），再点击“退出微调”；已保存修改仍保留。

“草稿”是当前调整中的临时状态，不是用户需要打开的草稿箱。用户判断进度时先看审核区是否显示“本轮预览 N 处，尚未保存”，再看保存后的银行进度即可。点击“确认并预览本轮”只生成预览；点击“保存本轮 N 处”才会一次性应用到本轮全部候选并完成本轮确认。微调处于活跃状态时，普通切换和导出会暂停；完成当前微调或显式退出后才恢复。退出不会撤销已保存修改，也不会把未保存预览当成已确认。

“本次范围内还剩 0 处”只表示本次选入的片段已完成，不代表整家银行的所有位置都做过人工审核。其他位置的自动边界正确时可以直接结束本次微调；只有主动继续调整时才准备尚未核实的页面。无法核实银行、其他银行及已被独立修改或人工确认的候选不会自动加入新位置。

## 银行来源如何分组

同一家银行的多个 PDF 合并为一个银行来源。例如，同一出具银行的 2025 年 7 月和 8 月 PDF 可以在同一个银行流程中依次核对。不同出具银行始终分开，不能因为标题相似、付款方或收款方开户行相同而合并。

系统只使用回单中已核实的出具银行标识和版式证据。银行标识或版式无法核实的片段会作为独立范围处理，不会跨未知来源自动同步。文件名不能作为银行身份依据。

如果当前银行显示“待核实来源”，本轮会明确提示“本轮仅处理当前 1 处，不会同步其他片段”。这表示银行或版式证据尚不足，不一定是 OCR 故障。部分文字型 PDF 的银行标识也是图片，需要本机 OCR 识别；这种情况下可在“帮助与反馈”中点击“检测 OCR”，检测正常后重新分析原 PDF。升级后也需要重新分析旧结果，才能重建银行和版式证据；仅退出再进入微调不会重新生成自动候选。

预览和保存范围以界面显示的“本轮 N 处”为准。显示 1 处时只处理当前片段，不会同时修改其余 7 处；银行与版式核实通过、同类片段纳入同一轮后，才会按本轮实际处数生成预览并保存。

每轮按同一银行、同一版式和同一位置组织。首栏、中间栏、末栏和只有一张回单的尾页需要分别抽查；尾页的单张候选不能因为该页只有一个命中就改用其他银行或其他版式的范围。

生成预览和保存本轮时只会同步严格匹配且边界合法的目标：目标必须仍属于当前任务，来源文件身份未变化，裁剪框不能超出纸张或侵入相邻回单。已由用户确认、独立手改、明确保留整页或无法通过校验的目标会被保护或跳过；仍是自动确认且未人工修改的目标可以按严格条件加入本轮。预览中的目标仍未写入，必须检查无误后点击“保存本轮 N 处”。

## 预览、保存和撤销

保存本轮是一次原子操作，样本和实际通过校验的同类目标一起保存。生成本轮预览时若版式检查失败或样本超出凭证保护边界，操作尚未写入，当前调整会保留；提示会指出对应边和超出的毫米数，并显示“本轮尚未保存”，可以继续调整后重试或点击“取消当前调整”。不需要移除来源或重新上传文件。若审核数据库写入失败或结果不明确，不能假定没有写入，也不能用取消来回退；只能点击“重试本轮保存”重试原请求，或点击“放弃失败操作并重新核对”，读取当前实际保存的审核决定并重置本次引导。两种情况下都不会把未经明确确认的部分目标当成已完成。

保存成功后，点击“撤销本轮”可以一起恢复本轮样本和同类目标的保存结果，并回到该轮原来的位置和样本。撤销不会影响已经完成的其他轮次或其他银行。预览尚未保存时点击“返回调整”即可继续修改；需要修改已确认的结果时，应先按界面提供的撤销或恢复路径重新进入相应位置。

如果当前轮没有需要移动的框，也必须通过“确认并预览本轮 N 处”生成预览，再点击“保存本轮 N 处”完成显式确认。自动高置信度、同步成功和框已经显示为绿色，都不代替用户检查和保存。

## 当前任务与异常恢复

当前任务会保留已经保存的裁剪框，普通导出可以依据持久化且有效的审核确认；本次微调引导的银行确认进度和撤销记录只在当前会话内有效。再次进入微调时，会建立新的引导会话，需要重新查看各银行的位置并明确确认，不能根据上次会话的按钮状态推断已经完成。若要继续处理，请保留原始 PDF 并在当前任务中重新分析。

出现版式校验失败时，操作尚未写入，先检查是否选错银行、版式或位置；生成本轮预览时若样本超出凭证保护边界，提示会指出对应的上、下、左或右边以及超出的毫米数，并显示“本轮尚未保存”。需要时展开“当前边界不合适”，使用“按单张候选分割”或“调整为整页范围”后继续调整，也可以取消当前调整。不需要移除来源或重新上传文件，取消后可回到结果页改选片段。若审核数据库写入失败或结果不明确，当前恢复操作会受保护，只能使用“重试本轮保存”或“放弃失败操作并重新核对”；后者会读取实际保存结果并重置本次引导，不能用“取消当前调整”或“撤销本轮”猜测写入是否成功。原生单页单栏回单可继续保留整页；多联版式的尾页和全部命中的多联页应按单张候选检查。

如果版本升级了版式计算规则，请使用仍保留的原始 PDF 重新分析，让新版计算版本重建版式证据和候选边界；不需要删除来源或重新上传文件。

进入微调后，活跃微调必须先完成或显式退出，才能恢复普通导出操作；退出不会把未确认片段当成已确认，也不会撤销已保存修改。点击“导出回单”时仍会检查未确认、阻塞、预览未完成和来源变化的片段，校验不通过就不能导出。没有进入微调的任务，检查自动结果后可以直接点击“导出回单”进入导出设置。

## 测试与隐私边界

自动化测试使用临时生成的合成 PDF、虚构交易文本和假的银行标识，覆盖自动候选正确时直接进入导出设置、跨 PDF 同银行分组、不同银行隔离、首中末栏及尾页、整轮预览、预览返回调整、一次保存并确认、整轮撤销、活跃微调退出和导出校验等行为。用户提供的真实 PDF、截图、账号和客户信息不进入源码、文档或测试夹具。

人工验收时请使用脱敏副本，重点检查：自动边界正确时能否直接点击“导出回单”进入导出设置；多联页全部命中是否仍逐张分割；单张尾页是否保持单张框；确认并预览本轮后是否显示“本轮预览 N 处，尚未保存”；预览中发现问题能否返回调整；生成本轮预览时样本超出凭证保护边界，提示是否指出对应边和毫米数且显示本轮尚未保存；首栏、中间栏、末栏微调是否分别同步；保存成功后是否只写入一次并直接进入下一位置；退出微调后未完成或阻塞片段是否仍被导出校验拦截；重新进入微调时是否重建本次引导进度并保留已保存框，普通导出是否仍依据持久化有效确认。
