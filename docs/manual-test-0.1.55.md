# 银行回单工作台 0.1.55 定向人工复检单

本单用于 **0.1.55 Windows 安装包**的定向复检。以下项目均待在干净 Windows 环境实际操作后填写；代码测试和打包成功不能替代安装验收。没有适用样本的项目记“未覆盖”，不要记为通过。

## 准备与安装

1. 在干净的 Windows x64 环境安装 0.1.55。另在保留 0.1.54 任务和模板的环境中覆盖升级至 0.1.55。启动后检查“帮助与反馈 → 版本与更新”显示 v0.1.55，原有模板仍可读取。记录安装包名称、SHA-256、系统版本和结果。
2. 准备含普通回单、疑似无效片段和特殊单证的 PDF **工作副本**，以及已保存的兼容版式模板。测试只读入工作副本，不改名、移动、覆盖或删除原件。
3. 操作前记录 PDF 原件的文件数量、各文件字节数和 SHA-256；结束后再次核对。PowerShell 可用 `Get-Item -LiteralPath $inputPdf | Select-Object FullName, Length` 和 `Get-FileHash -LiteralPath $inputPdf -Algorithm SHA256`。

## 定向复检

### 1. 分析处理步骤提示

1. 分析工作副本，进入“检查与处理”。核对顶部提示顺序与界面操作一致：“核对并排除无效 → 核对特殊单证 → 应用模板或微调 → 逐栏复核（可保存或更新模板） → 检查预览 → 导出”。保存模板应是可选操作，随已核对栏位进行，不应显示为每次必经步骤。
2. 检查提示在 1920×1080 和当前系统缩放比例下不遮挡标题、计数或按钮；窄窗口下可阅读，不会误导用户跳过待复核直接导出。记录实际显示文字和截图。

### 2. 模板保存页文案与范围

1. 选择一处普通回单，进入“调整所选边界”，微调后点击“确认并预览本轮”。核对本轮变化数、风险项和模板可写入栏位数；不要把“本轮变化数”理解为已核对模板栏位数。
2. 勾选“保存为版式模板”。确认本轮模板说明字号比主操作文字小、句子简明，仍明确提示：一套多栏模板可分次核对各栏；尚未核对的栏位不会因保存本轮自动写入模板；已排除片段如因边界变化失去原排除决定，应单独提示。
3. “新建一套模板 / 更新已有模板”旁应以较小灰字说明：新建不会覆盖旧模板，更新须明确选定已有模板。银行名称输入框旁应以较小灰字说明名称用于整理查找，模板适用仍由出具银行、凭证类型和版式核验。核对提示位置、折行和对齐。
4. 分别尝试新建与更新兼容模板。只对经本人确认的真实栏位执行保存；保存后检查“我的模板”的名称、栏位和版本。不要把仅查看或切换页面算作核对。

### 3. 已排除与特殊片段的视觉区分

1. 在“片段总览”找到疑似无效片段和特殊单证，确认前者有醒目的疑似提示、后者有特殊单证标记。对确属无效的片段执行显式排除；对有效特殊单证检查边界后确认。普通回单按需应用模板或微调，处理本轮风险并逐栏复核；需要复用已核对栏位时再保存或更新模板。
2. 待复核计数变为 0 后回到“全部 → 片段总览”，定位已排除与已确认特殊单证相邻的页面。**已排除片段仍应保留区别于普通回单的视觉填充或边框**，且显示“已排除”；已确认特殊单证仍保留特殊单证标记。对照“已排除”筛选及详情状态，检查视觉与真实状态一致。
3. 切换片段总览、原页总览、来源和状态筛选，再返回同一位置；上述标记不应消失。已排除片段不得进入导出范围，特殊单证不得被当作普通回单自动套用模板。

### 4. 导出与原件保护

1. 确认仍有待复核片段时不可直接导出；待复核全部处理后进入导出设置。核对导出数量不含已排除片段，按所选方式导出到新的测试目录；检查生成的 PDF 可打开，普通回单及特殊单证边界正确。
2. 再次核对 PDF 原件的文件数量、字节数和 SHA-256 与操作前完全一致。若应用出现错误或处理结果不明确，记录具体页码、栏位、操作和截图，不重复点击可能写入的按钮。
