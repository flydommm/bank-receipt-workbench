# 银行回单工作台 0.1.54 定向人工复检单

本单用于 **0.1.54 Windows 安装包**的定向复检。以下结果均待安装后人工填写；源码测试、打包成功及开发机启动不等于干净 Windows 验收。若样本不具备某种单证或冲突条件，记“未覆盖”及原因。

## 准备与安装

1. 在空白 Windows x64 测试环境新装 0.1.54；在保留 0.1.53 测试任务和模板的另一环境覆盖安装 0.1.54。分别启动应用，在“帮助与反馈 → 版本与更新”核对显示 v0.1.54；升级环境还应核对原有任务和模板可读取。记录安装包名称、SHA-256、系统版本和实际结果。
2. 准备含普通回单、同页疑似无效栏位、特殊单证的 PDF **工作副本**，以及已保存的同银行同类型同实际版式模板。另备一页已有人工确认或人工分类的任务数据；可准备不同银行或不同版式样本检验隔离。仅导入工作副本，不改名、移动、覆盖或删除原件。
3. 操作前记录每份 PDF 原件的路径、字节数和 SHA-256；完成后对相同路径重新计算并比对。例如在 PowerShell 中使用 `Get-Item -LiteralPath $inputPdf | Select-Object FullName, Length` 和 `Get-FileHash -LiteralPath $inputPdf -Algorithm SHA256`。测试过程中不要编辑原件。

## 定向复检

### 1. 总览提示与显式排除

1. 分析工作副本，在“分析处理 → 片段总览”检查“待复核 N”“已排除 N”和“疑似需排除 N”。切换“原页总览”，对照同一疑似栏位的原页和片段详情。
2. 点击“疑似需排除 N”：应只筛出待核对的疑似无效片段，**提示和勾选本身都不改变审核状态**。先检查内容，再勾选目标，点击“排除所选疑似无效 N 处”；不要把仍有效的回单排除。
3. 检查所选项转为已排除、待复核数随之变化；在“已排除”筛选中恢复其中一项，确认它回到待复核，且不会自动变成已确认。切换来源、凭证类型或状态筛选后，之前的勾选应清空；“全选当前筛选结果”只选择当前命中的片段。

### 2. 特殊单证与人工分类

1. 对样本中实际存在的贷款清算通知书、贷款利息到期通知书、电子缴税付款凭证，核对原页标记、凭证类型和待复核状态；点击“核对特殊单证 N 处”集中查看。若没有某一类型，单独记为未覆盖。
2. 边界完整时使用“确认此特殊单证”或“确认所选特殊单证 N 处”；边界有误时先“调整所选边界”再确认。未自动识别的特殊单证通过“设置凭证类型”人工标记，并核对其仍需按实际边界审核。
3. 检查特殊单证与普通回单的边界、类型、审核状态各自独立；特殊单证不能因普通回单模板应用而变成普通回单或自动确认。

### 3. 同页排除后预览应用模板

1. 在含多个普通栏位的同一页，明确排除一个无效栏位，保留其他普通栏位待复核。把第 1 节为验证恢复而重新纳入的无效栏位再次明确排除；处理当前来源中仍待复核的特殊单证和其他疑似无效提示，使“我的模板 · 预览应用”入口出现。
2. 从“来源与类型”点击“我的模板 · 预览应用”，选择已核对栏位的兼容模板，再点击“预览应用到当前结果”。核对预览标题“预览模板应用范围”、可应用页数、保留的已排除片段数、未应用页数及“变化说明”。即使左侧只筛选一份 PDF，预览范围也应按**当前任务所有兼容来源**计算。
3. 逐项查看受影响片段和风险；无阻断且风险核对完成后点击“应用模板并复核 N 处”。确认同页原有已排除片段的边界和排除状态保持不变，模板只替换已核对栏位，受影响的普通片段进入待复核；导出入口须等所有未排除的待复核片段处理完成后才出现。

### 4. 跳过、阻断与撤销

1. 在模板预览的“变化说明”核对跳过原因和页数。已有人工确认、人工分类或特殊单证的页面应保持隔离；出具银行、页面尺寸/方向、版式或栏位结构不兼容的页也不得套用。若同页已排除栏位与模板公共页边距不兼容，应整页跳过，并在预览中列出原因。
2. 如果预览出现“以下问题仍需处理，本轮不能保存”，或提示“应用模板可能改变已排除片段的边界或命中证据”，确认“应用模板并复核 N 处”按钮不可用，原有排除决定不变。仅在具有可复现冲突的测试数据时判定此项通过；普通样本未触发则记“未覆盖”，不要改造原件或绕过阻断。
3. 应用成功后点击“撤销本轮”，比较应用前后的页/栏边界、已排除、已确认、人工分类和待复核状态，确认恢复本轮前状态。若保存或撤销结果不明确，只用界面提供的“核实并完成保存 / 核实并完成撤销”继续核实同一笔操作。
4. 结束后复核原件的文件数量、字节数和 SHA-256 均与准备阶段一致。
