# 0.1.60 版本说明

Windows x64 Core。安装包通过维护者交付，本轮源码整合不自动创建 GitHub Release，也不更改仓库可见性或许可证。

## 本版改动

- 清除、更换来源或更正本批资料后，默认进入“选择本机档案”，同时清空旧账户绑定，要求重新选择。
- 回单导出增加持续可见的阶段、已完成量、阶段百分比和已用时间。生成页面可计数，写入及校验等未知阶段使用不定进度；成功、失败、重试、取消目录和离开上下文均管理独立状态。
- 进度通过本地引擎有界 JSONL 帧和单次 Tauri Channel 传送，仅含阶段及数量，不携带业务名称或路径；旧单响应调用保持兼容，导出仍需最终响应确认成功。
- 使用反馈移除 GitHub 公开入口，保留本地预览、复制、保存 TXT 及用户主动选择的邮件和微信联系。
- 同步帮助、设置说明、README 和使用指南；内嵌模板下载、完整导入预览、批量修正交易对手与读取规则按现行步骤说明。
- 过期开发待办、真实样本验收及本机交付记录归档到本机忽略目录，保留有效的合成回归测试、锁文件、CI 和第三方许可。

## 验证边界

对应本版源码的自动检查、安装包校验和人工操作结果随交付记录保存。旧版的平安大样本性能记录只作背景，不作为 0.1.60 的新性能承诺。进度功能帮助判断任务状态，不保证各台电脑有相同导出时长。

Core 不包含 OCR。陌生版式、空白或不确定对手以及边界问题仍需用户检查。发布脚本中的 clean_windows_verified 保留构建时状态，不能替代实际安装验收。
