# 银行回单工作台 0.1.46 定向复检单

目标包：`0.1.46 Core x64 NSIS`。本单只复检 0.1.45 复检中确认的“微调保存越过范围写入审核状态”修复，以及与该修复直接相邻的模板范围、真实风险和导出门控。已经通过的 M01–M35 不因版本号变化重跑；本单所有人工结果初始均为“待测”，工程自动化和源码/工作副本验证不能替代安装包内操作。

相关背景：[0.1.45 微调保存验证记录](verification-0.1.45-calibration-scope.md)、[0.1.45 定向复检单](manual-test-0.1.45.md)。

## 测试边界与开始前记录

- 在干净 Windows 或已安装 0.1.45 的环境中安装/覆盖安装 0.1.46，打开“帮助与反馈”确认版本为 `v0.1.46`。不恢复旧历史任务作为本轮输入。
- 使用 SH-A（上海银行、26 页、包含特殊单证）的独立工作副本。不得覆盖、移动、改名或删除原始 PDF；测试开始前记录副本的文件数量、字节数、文件名和 SHA-256，结束后再次核对。
- 记录 Windows 版本、分辨率、DPI、WebView2、样本页数和每个检查点的计数。若当前样本与既有记录的候选数量不同，以实际值为准，不为了得到预设数字改动样本或数据库。
- 本轮验证的核心是“只保存选中的 1 处”。应能在 SH-A 第 1 页建立以下混排状态：第 1 栏为“其他特殊单证”且待复核，第 2 栏为已排除，第 3 栏保持自动候选；其他页至少保留一个待复核特殊单证。若无法建立该状态，记录阻塞原因，不得用推测替代结果。

## 1. 安装和初始计数

1. 启动 0.1.46，新建任务，添加 SH-A，选择“分割全部回单”并完成分析。
2. 在“片段总览”记录检查点 `C0`：候选总数、待复核数、已确认数、已排除数，以及自动候选/待复核/特殊类型的数量。记录第 1 页三栏和其他待复核单证的当前状态及边界。
3. 对第 1 页第 1 栏设置“其他特殊单证”，但先保持待复核；对第 1 页第 2 栏执行“排除所选”；确认第 1 页第 3 栏仍为自动候选。记录检查点 `C1`。

**预期：** 分类只作用于第 1 栏，排除只作用于第 2 栏；候选总数不因分类/排除改变。`C1` 的待复核和已排除变化应能由实际选中的片段解释，不能出现整页或其他来源的连带变化。

## 2. 单栏保存范围隔离（本轮核心）

1. 只选第 1 页第 1 栏进入“调整所选边界”，只改变这一栏的高度或边界；不要选择第 1 页第 2、3 栏，不要启用统一三栏高度、公共边距或跨页同步。
2. 预览本轮并记录 `C2`：本轮影响的来源、页、栏位和数量。确认范围只有第 1 页第 1 栏；确认第 2 栏的排除状态仍可见，第 3 栏仍未被选中。
3. 保存本轮 1 处，返回结果后记录 `C3`，逐项抽查：
   - 第 1 页第 1 栏：本轮边界和人工特殊类型按预期保存，成功保存后进入已确认；
   - 第 1 页第 2 栏：仍为已排除，边界、类型和排除状态不变；
   - 第 1 页第 3 栏：仍为原自动候选/原自动风险状态，没有被补写成“已确认”；
   - 其他页的自动候选和待复核片段：审核状态、特殊类型、排除状态、边界和审核时间不因本轮 1 处保存而改变。
4. 对未选集合 `U` 记录保存前后数量以及至少三类代表项（同页未选栏、其他页自动候选、其他页待复核特殊单证）。预期 `|U|` 不变，代表项的状态字段和边界均不变；变化只能发生在第 1 页第 1 栏。

**预期计数关系：** 候选总数保持不变；已排除数只反映第 2 栏；待复核数只能按第 1 栏的明确确认结果变化，不能因为保存 1 处而批量减少；自动候选不应凭空增加人工审核记录。若界面只显示汇总数字，必须结合片段卡片、页码/栏位和截图核对，不能只凭总数判定通过。

## 3. 撤销、重开与真实风险保留

1. 在 `C3` 后执行“撤销本轮”或等效撤销操作，记录 `C4`。确认第 1 栏恢复到保存前的边界和审核状态；第 2 栏仍排除；第 3 栏及其他页状态与 `C1` 一致。重复点击撤销不应继续改动计数。
2. 关闭并重新打开应用，记录 `C5`。若当前任务能恢复，确认没有新增确认记录、丢失排除状态或改变特殊单证类型；若启动后进入新任务，则原任务重开标记为“不适用（持久化由工程回归覆盖）”，另行分析新任务，确认不继承前一任务的人工分类、审核与排除。不能把重新分析当成恢复原任务的证据。
3. 在独立校准轮次中，将一个选中的栏位缩小到能触发真实内容/边界风险的位置，形成预览但不要强行保存。确认风险仍显示在对应片段；未选栏位原有待复核风险仍保留，不因同一页重算或保存范围变化而自动确认。若样本无法安全触发真实风险，记录“未触发”，不得改用空白页或手工数据库数据伪造通过。

**预期：** `C4` 恢复到 `C1` 的有效状态；`C5` 按实际启动行为区分原任务恢复与新任务隔离。真实风险不能被“保持自动状态”的逻辑吞掉。

## 4. 模板确认范围抽查

1. 在普通三栏回单的独立小任务中，只调整并确认一个实际栏位，保存为版式模板；记录模板名称、银行、凭证类型、实际版式、版本和实际确认栏位数。
2. 检查模板详情或“我的模板”，确认模板的“已确认栏位”标记只包含本轮实际确认的栏位，不把同页未选栏位、其他页自动候选或仅有风险提示的栏位推导为已确认模板范围。完整页面结构可以保留三栏，但不代表三栏都已确认。
3. 用同银行、同凭证类型、同实际版式的新 PDF 选用该模板，确认只复用已保存边界，不继承旧关键词、审核、排除或特殊分类状态。若模板更新或停用后重试，确认当前显示的名称、版本和可用状态与实际选择同步。
4. 若本轮含人工“其他特殊单证”分类，确认该人工分类页不会被登记成普通回单可复用模板；自动识别且未被人工覆盖的同型特殊单证仍按原兼容规则处理。

**预期：** 模板确认范围与实际选择一一对应；未确认栏位和人工分类状态不被模板扩大或跨任务继承。

## 5. 导出门控抽查

1. 在 `C3` 或其他仍有待复核片段的结果页观察阶段按钮。记录 `C6`：候选总数、待复核数、已排除数和导出入口可见/可用状态。
2. 待复核大于 0 时，确认不显示“导出回单”入口；不应通过当前筛选或微调保存绕过门控。保留的待复核片段不应被静默丢弃。
3. 在小任务中先完成特殊单证确认或排除，再确认普通回单，直至待复核为 0；记录 `C7`。确认导出入口只在清零后出现或可用，导出范围包含所有未排除项，排除项不进入 PDF/XLSX。
4. 如本轮实际导出，使用独立输出目录，记录 PDF、XLSX（若勾选）和清单 JSON（若勾选）的文件清单；再次核对输入副本数量、字节数和 SHA-256。若没有清零条件或未执行导出，标记待测/阻塞，不将工程导出结果代替人工结果。

**预期计数关系：** `C6.pending > 0` 时导出不可用；`C7.pending = 0` 且排除状态已明确时导出可用。候选总数不因门控变化，导出数量只由确认和排除结果决定。
