# 0.1.45 Core 特殊单证分类与隔离交付

本版支持分析后单个或批量设置凭证类型，将类型分类与边界核对分开；用户明确勾选“类型与边界均已核对”时可同时完成审核。操作顺序为特殊单证与排除项、普通回单与模板、导出。新任务默认“分割全部回单”，自动识别补充贷款清算通知书。

含人工分类的页面退出普通跨页版式同步，微调只修改所选栏位，锁住邻栏、统一高度和公共边距。人工覆盖页本轮不保存可复用模板；自动识别且没有人工覆盖的同类型、同实际版式特殊单证继续沿用原有模板规则。分类不自动合并误拆片段、不自动扩大为整页。排除、恢复、普通确认及局部微调保留未涉及片段的分类和审核状态；分类变化使旧校准预览与导出范围失效。
