# 0.1.48 银行多模板交付记录

0.1.48 支持同一家银行保存多套独立模板，不按公司划分。新建模板从 v1 开始；更新必须明确选择目标模板，改名、停用和部分栏位继承只作用于该模板。多个模板同时适用时提示用户选择后重新分析，不静默选择最新模板或混用边界。匹配仍受银行身份、凭证类型、实际版式、页面几何及栏位约束。

本轮已完成源码提交、Windows 安装包构建、打包资源验证和 PDF 定向复检单。**0.1.48 的干净 Windows 安装与 GUI 定向复检尚未执行**；工程结果不代替人工结果，已通过的历史 M01–M35 不要求整套重跑。

## 本轮定向复检范围

安装后按 PDF 复检单依次记录：覆盖升级与旧模板保留 → 同银行两套模板并存 → 指定更新和未确认栏位 → 多套匹配提示与手动选择 → 改名/停用隔离 → 跨银行和特殊单证隔离 → 原件完整性。各 GUI 结果当前均为待测试。

关键词按本次任务的处理方式和搜索条件执行，历史关键词仍可保留供选择；新任务不继承旧任务审核、排除或人工分类状态。模板保存的已核对边界与本次任务的人工审核状态分别处理。

## 保留边界与恢复点

- 同银行的模板仍须实际版式匹配；不能仅凭名称或三栏数量跨银行、跨类型套用。
- SH-A 身份不足的已知限制仍保留：可保存当前 PDF 的本轮边界，不能因填写银行名称就获得跨文件模板身份。
- Core 包不包含 OCR 运行时；WebView2 缺失场景仍是独立未验证项，不要求为本轮模板改动重做此前已通过的环境测试。
- 旧模板迁移、写入和恢复行为使用隔离测试库验证；本轮打包未操作真实业务 PDF 或用户模板库。
- 上一个已完成定向验收的版本及安装包见[0.1.47 交付记录](delivery-0.1.47.md)，对应记录提交为 `9342862a6a43ab6bba9982e214666e553e5a43d9`。旧包和 Git 恢复点均保留；旧版本回退运行仍需考虑新版模板库兼容性，不将保留旧包等同于允许旧程序写入新版数据。
