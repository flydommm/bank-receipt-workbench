# 0.1.63 版本说明

Windows x64 Core。本版修复无可识别标题的表格回单被内部行线和文字间距拆成多个候选框的问题。

## 本版改动

- 先拼接同轴短边并识别完整闭合表格，按结构生成候选框；不依赖银行名称白名单、文件名或交易值。
- 将可明确归属的 Logo、底部说明、图片印章和矢量印章纳入边界，包含与表格相交或位于表格外的矩形印章。
- 独立的上下表格分别保留；共用外框中的分联需要独立重复页眉图像支持，避免把较高的合并备注栏误判为回单间隔。
- 内容归属不明、跨表图形、左右并排或几何分析超预算时继续保留待复核机制，不放松导出确认要求。
- 升级后重新分析原 PDF 才会生成新边界，已有任务快照不会自动重算。有明确标题的原识别路径保持原有行为。

## 验证范围

- Python 解析、版式、搜索、裁切和导出相关回归测试：543 项通过，其中包含 30 项本次专项用例。
- 专项用例覆盖不同银行名称、无银行名称、不同纸张尺寸、一页 1／2／3 张回单、共用外框、高合并备注栏、图片和矢量印章，以及搜索导出隔离。
- 本地 131 页样本重新分析为每页 1 个候选，未产生跨框或框外内容诊断；抽查首页、第二页和末页的实际裁切结果完整，原件哈希未变。
- 独立代码复审通过。上述检查不代表任意陌生版式都可免复核；混合标题和左右网格不在本次自动识别扩展范围内。
- 安装包构建、资源核验、签名状态和 Windows 安装验收以本次交付清单为准，本说明不将源码测试视为安装验收。
