## 产品契约

1. 原页总览每卡一页，片段总览每卡一个候选；连续滚动、缩略图大小调节、详细预览返回保留位置。
2. 未分析的来源也支持原页总览。分析后原页总览包含无命中页，页卡显示该页候选数；选整页只选择当前明确范围内的候选，界面说明选择了多少片段。
3. 勾选仅选择对象，确认按钮才改变审核状态。全选为“当前筛选结果”，不是已渲染卡片，也不包含筛选外项目；切换来源/类型/状态筛选清空选择。
4. 来源、普通/特殊类型、待复核、已排除可筛选。单选详情用于大图和边界编辑，多选工具仅在选择后显示。已识别特殊类型单独呈现，未知类型不能假装已识别。
5. 批量确认每条保留自己的边界；批量排除不删除原件；恢复排除回到待复核。禁止被阻断项目通过普通确认绕过问题。写入前后验证权威记录，丢失响应、部分失败和任务切换不能误报成功。
6. 边界微调继续使用既有银行、类型、实际版式、页面几何隔离及本轮预览/保存/撤销机制。勾选范围不等于版式同步范围，调整前显示本轮实际范围。
7. 三阶段：导入分析 → 检查处理 → 预览导出。未完成待复核不显示导出入口；阶段改变不丢失草稿。导出文案改为“预览并导出/导出设置”，准确表达导出所有未排除项。
8. 复用现有诊断提示边界/特殊问题，不新增未经验证的自动业务排除规则。自动检测能力不能自动排除有效凭证。
