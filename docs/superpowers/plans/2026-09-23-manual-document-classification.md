# 人工凭证分类与分阶段审核

状态：实现、定向验证及整合检查完成。用户随后授权的提交与 0.1.45 Core 安装包制作已完成，工程证据及复检入口见[0.1.45 交付记录](../../delivery-0.1.45.md)。本轮干净 Windows 人工验收待测；未推送。

## 用户目标

分析后允许单个或批量将片段设为特殊单证，也允许纠正为普通回单。先处理特殊单证与排除项，再处理普通回单及模板，最后导出。分类和边界审核分别记录，用户明确核对两者时可以在一次操作中完成。

## 实施决定

- 自动识别继续作为类型建议。人工覆盖绑定到具体原件 SHA、页及片段身份，不能把同页其他片段改成特殊类型。
- 审核编辑和记录追加可选 `document_type`：普通、其他特殊及三种已知特殊类型。省略时沿用自动类型；已有人工覆盖在之后确认、排除、恢复时保留。使用现有记录修订和原子保存，不创建第二套审核数据库。
- 默认只保存分类并保留待复核。用户显式勾选“类型与边界均已核对”才同时审核通过。已排除或阻断项不能借分类绕过原流程。
- 校准和导出使用有效分类及当前审核修订。分类变化使旧校准预览和导出范围失效；其他片段的审核结果不因这次分类重置。
- 有人工覆盖的页面退出普通跨页版式同步。该页单独调整仅允许所选栏位，锁住其他栏位和公共边距，防止统一高度扩散。自然识别且没有人工覆盖的页面仍使用原有同类型、同版式同步。
- 人工分类不提供可靠的跨文件版式证据：该轮不保存可复用模板；自动识别的已知特殊版式仍可以使用原有模板流程。“其他特殊单证”不是统一版式名称。
- 分类不修改框、不自动设为整页、不合并片段。实际结构错误必须通过独立的明确边界/结构修正处理，不得把类型审核误称为误拆修复。

## 分工

- 持久化：Python 审核模型、审核存储、有效类型读取及模型/库/API 回归。
- 隔离：Python 校准准备、预览、保存和模板注册，覆盖混排、关键词未命中邻槽及旧预览冲突。
- 前端：类型协议、分类操作面板、批量控制器、校准保护控件、状态及类型提示。
- 主代理：整合、安全边界检查、用户指南、集成验证与实际产物审阅。

## 验收

1. 自动识别建议、人工设置、改回普通、重新读取、批量选择范围正确。
2. 只分类不自动通过；明确核对可以完成分类与审核；排除和阻断没有旁路。
3. 保存失败、冲突或丢失响应不静默覆盖并发分类，界面反映实际结果。
4. 人工特殊与普通在不同页、同页及关键词部分命中的情形均隔离。
5. 微调和撤销保留未触及片段的分类与审核，旧准备/预览/导出不能继续使用。
6. 人工覆盖页禁止模板保存，自动特殊模板原流程不受影响。
7. 原件只读；真实样本验证只使用独立工作副本，前后核对大小和 SHA-256。
8. 前端相关测试、Python 审核/校准/导出测试、生产构建和公开源码扫描通过后交付。
