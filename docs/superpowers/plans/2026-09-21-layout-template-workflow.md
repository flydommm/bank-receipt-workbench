# 已核对版式模板工作流

用户于 2026-09-21 确认：保存已核对回单边界为模板，新 PDF 可自动匹配或手动选择；支持查看、更新、停用；不再保留历史任务入口。

操作说明见 [版式模板使用说明](../../layout-template-guide.md)。

## 交付范围

- 来源面板以“我的模板”替换“历史任务”；不提供旧任务列表入口，后台任务持久化、处理中状态与旧数据库保留。
- 模板库展示框位示意、纸张尺寸、名称、版本及状态，支持选用、重命名和停用。
- 核对后的微调保存提供显式“保存为版式模板”，可命名；同版式更新有效版本。边界更新始终通过真实 PDF 的微调和核对，不直接编辑模板几何。
- 分析默认自动匹配；手动选择仅限定候选模板，仍检查银行、凭证类型、版式、物理纸张和位置证据。只复用边界，不继承旧关键词命中或审核结论。
- 停用整版式族，避免停用最新版后回落旧版。模板几何快照固定于任务，运行或续跑不受其后管理操作影响。
- 不删除历史任务，不迁移未审核任务为模板，不触碰业务原件，不变更版本号或重新打包。

## 接口和文件归属

1. 后端：`engine/layout_template_store.py`、`receipt_layout_history.py`、`receipt_layout_reference.py`、`receipt_calibration_journal.py`、`batch_store.py`、`batch_api.py`，以及 `src-tauri/src/batch_service.rs`。
   - `batch_layout_template_list {active_only,offset,limit}` 返回 `{items,total,next_offset}`，每页最多 50。
   - `batch_layout_template_rename {template_id,name}` 返回模板；既有停用接口作用于同版式族。
   - 校准保存新增可选 `template_name`；创建回单任务新增顶层可选 `layout_template_id`，空值自动、字符串手选。
   - 手选模板由后端校验并在创建事务内冻结；不放入 `processing_options`，不改变关键词指纹和结果 DTO。
   - 有界读取有效模板，不因重复旧版本超过 256 行而让全部模板失效。
2. 前端组件代理：`layoutTemplateClient.ts`、新 `LayoutTemplateManager`、`ReceiptCalibrationWorkspace`、校准控制器及客户端和对应测试。
3. 主代理：`App.tsx`、`SourcePanel`、回单创建请求编解码、入口与分析提示、集成测试、说明文档与最终审查。
