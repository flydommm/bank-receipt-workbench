# 总览与直接导出流程调整

依据 2026-09-23 用户对 0.1.43 的实际操作反馈实施。用户已明确界面与流程方向，本轮在现有结构内调整，不改变银行、凭证类型和实际版式的模板匹配边界。

## 范围与决定

1. 添加或切换来源后默认原页总览；保留单页预览。
2. 分析选项依次为“分割为全部回单”“查找提取回单”；保留已有默认模式，处理方式分组仅保留可访问名称。
3. 自动候选、已确认片段仍可单选或打开详情后微调并保存模板；待复核筛选为空时提供切换全部入口。排除项先恢复再调整。
4. 导入和检查总览使用相同缩略图缩放控件：减号、百分比、加号。
5. 三阶段为“导入分析 → 检查处理 → 导出文件”。待复核清零后进入导出设置，直接选择目录并导出，不再要求用户生成和浏览第二份导出预览。
6. 导出设置保留方式、可选 XLSX，新增默认关闭的 JSON 清单。用户可改导出名称；建议值只从已提交的来源文件名、处理模式和包含关键词生成。
7. 内部冻结范围、生成 PDF、校验、原子发布和恢复均保留。JSON 清单属于可选外部文件，不影响内部审计。重试复用同一 intent 和目录。

## 文件边界

- 总览 UI：ReceiptBatchEntry、SourceDocumentPreview、ReceiptOverview、共享 ThumbnailSizeControl。
- 导出 UI/协议：ReceiptExportWorkspace、exportNaming、exportBundleClient、ReceiptWorkflowSteps。
- Python/Rust：export_scope、receipt_export_scope、export_bundle、export_publish、export_journal、Tauri export_bundle。
- 联动帮助与测试：当前用户指南、HelpCenterDialog/helpContent、组件及 App 流程回归。

## 验证重点

- 已确认项仍能微调，模板保存流程保持；排除与恢复不越过筛选范围。
- 默认总览、切源、统一缩放以及查找/全部分割语义准确。
- 取消选目录无文件生成；重复点击只有一次事务；审核/任务变化拒绝过期结果；离开时不与发布争抢清理。
- JSON false/true/缺省精确合同；缺省维持旧合同与摘要；关闭后和中断恢复仍验证文件身份、哈希与顶层冻结选择。
- 安全命名和有意义前缀不改变原件；前端、Python、Rust相关测试和构建。
- 新版未打包前不把本轮行为记作旧安装包已验收结果。
