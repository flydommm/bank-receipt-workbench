## 本轮修改与验证

- 原件及结果预览的短读操作复用引擎进程，减少每次切换页面时重复启动 Python 和导入模块的开销。来源校验与数据库读取仍逐次执行；坏响应、退出和超时会回收进程。
- 分析时共用当前私有 PDF 生命周期内的逐页版式描述，减少重复计算；优化像素比较的临时分配，保持原有判定阈值。
- 本机 HX-A 671 页、MS-B 161 页对照的完整 checkpoint JSON 逐字节一致；预览请求与 PNG 也一致。计时范围、数字和限制见[性能修复记录](performance-2026-09-19.md)，不以本机引擎耗时替代干净系统的完整操作耗时。
- 实施阶段 Python 定向回归 98 项及像素/可见版式回归 29 项通过；Rust 宿主和进程集成验证详见性能记录。升版后引擎协议 107 项、帮助与版本相关前端 22 项通过。
- 发布脚本完成固定依赖、私有运行库、PE/CRT、引擎健康、PyMuPDF 缓存、公开树检查和 TypeScript/Vite、Rust、NSIS 构建。主程序文件版本、产品版本与引擎健康版本均为 0.1.36。
