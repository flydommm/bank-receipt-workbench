# 0.1.37 Core x64 人工复测单

本单用于 0.1.37 Core x64 NSIS 的干净 Windows 与覆盖升级复测。完整项目仍按[人工测试清单](manual-test-checklist.md)的 M01-M35 稳定编号记录；本单提供本轮优先顺序和导出门控重点。

## 本轮边界

0.1.35 和 0.1.36 的用户反馈只作历史依据，不自动计为 0.1.37 通过。本单已于 2026-09-20 按用户本轮 M01-M07 反馈更新；通过结论仅覆盖已反馈操作，未测试或尚未反馈的子项继续单列，不推定为通过。

本轮重点验证以下行为：

- 当前结果存在任一“待复核”时，不显示“选择导出范围”，也不能进入“生成预览”；不额外显示门控解释文字。
- 最后一项待复核确认完成后，且结果非空，才显示导出入口。原本自动可用、没有待复核的候选无需再手动保存一次。
- 全部分割的默认合并文件名为“全部回单.pdf”；关键词搜索的默认合并文件名为“全部匹配结果.pdf”。合并、按来源分别导出、合并版和来源版同时导出都要复测。
- 任务、结果版本、候选集合或审核状态变化后，旧导出预览、旧发布状态和迟到响应不能继续显示或发布。
- 已保存微调后的主操作返回结果页；整页栏位微调仍须复测拖动、数字输入、复制尺寸和统一高度。

以上是本轮实现边界。整体按钮重排、最终预览右栏改为文件导航等更大的界面整理仍属于提案，不按本单预先写成已实现。

## 复测顺序

### 1. M01-M06：安装、来源与原件预览

1. 在干净 Windows 使用安装器默认目录安装；启动后核对版本、edition 和数据目录。若测试覆盖升级，先记录旧任务，再直接运行 0.1.37 安装包。
2. 新建任务加入 HX-A，不开始分析，确认原件预览、缩放、首页、上下页和回看已看页面均可用。
3. 再加入 MS-B，在来源之间快速切换；最后移除其中一个来源。

预期：来源切换和翻页最终显示最后一次选择；移除来源只影响任务，不删除磁盘原件。M03 另外验证卸载策略、保留数据和重新安装启动。

### 2. M07-M14：分析、关键词和候选框

1. HX-A 使用一个存在的关键词完成分析，再换另一个存在的关键词；抽查首、中、尾栏以及两次都命中的同一回单。
2. 清空关键词，选择“不输入关键词，分割全部回单”，分别检查 HX-A 第 669 页三栏、第 671 页双栏及原生单栏；再检查 MS-B 的混合标题页。
3. 记录点击“开始分析”到结果可操作的完整时间，单独记录“载入结果”；不要把进度数字走完直接当作结果已完成。

预期：关键词只改变命中集合，不恢复同一 PDF 的已保存边界；全部分割按当前模式完成分析。若仍出现与当前模式无关的关键词操作，记录为界面反馈，不预先判定为本轮已修复。候选框不能重复覆盖相邻栏位，尾页不能凭空生成不存在的栏位。

### 3. M15-M24：确认、整页微调和历史参考

1. 对原本无需复核的自动候选直接进入导出；对待复核但原框可接受的候选，保留原框确认，不要求先进入微调或保存一次。
2. 在普通三栏页进入整页微调，分别拖动边界、输入数字、复制当前框尺寸到其他栏，并统一三栏高度；确认并预览本轮。
3. 检查本轮风险列表的单选、多选、全选、取消全选、返回调整、保存本轮、取消本轮和撤销本轮。保存后应以“返回结果”为主操作。
4. 使用同银行同实际版式的另一份 PDF 检查保存版式；再用不同银行、凭证类型或栏数的样本，确认不会错误套用。任务、结果版本或候选集合变化后，旧预览不得复活。

预期：几何调整只在确认/保存对应步骤落盘；统一高度按页面边界校验，若上边界或下边界发生回移、越界或提示错误，记录实际数值和截图；双栏尾页只处理实际存在的两栏。特殊单证按凭证类型和实际版式单独分组。

### 4. M25、M34、M35：导出入口、目录和待复核门控

先准备一个仍有待复核项的结果，逐项执行：

1. 在有待复核时检查结果页：页面上不显示“选择导出范围”，也不显示“生成预览”或其他替代导出入口；不要以按钮灰色代替隐藏。
2. 确认部分待复核项后再次检查，入口仍应隐藏；不需要为了通过门控而移动候选框。
3. 确认最后一项待复核后，且结果非空，导出入口才出现。进入导出设置后生成预览。
4. 分别测试“合并为一个 PDF”“按来源分别导出 PDF”“合并版和来源版同时导出”，再测试 XLSX 索引、取消、错误恢复和成功后移除本次来源。
5. 在设置中指定输出目录，选择目录并导出；核对实际写入输出目录，不应跳转或写入输入目录。核对默认文件名与生成文件名。
6. 让任务或审核状态发生变化后返回导出流程，确认旧预览和旧成功状态失效，不能发布过期结果。

预期：有待复核时无需额外文字说明，导出入口直接不显示；全部确认后才可导出。生成预览数量、PDF 页数、来源顺序和文件名必须一致；输入原件保持不变。

### 5. M26-M32：原件保护、性能与环境

- M26：导入、分析、微调、导出和移除来源前后，核对原 PDF 文件数量、字节数和 SHA-256。
- M27：分别记录冷启动、原件首次显示、连续切页、结果切片段、分析和结果载入时间；HX-A、MS-B 各测一次，注明实体机/虚拟机和本地/共享目录。
- M28：Core/OCR edition 按实际安装包记录；没有 OCR 条件时写明未测原因。
- M29：检查不同页面尺寸、方向、缩放和打印预览，不把应用内缩放当作打印通过。
- M30-M32：本轮只验证结果页、待复核确认和保存后的主操作与导出门控；字体、长文案、窄窗口、高 DPI、帮助和键盘焦点不重叠、不截断。整体阶段按钮归并仍是提案，观察到的现象单独记录。
- M04：在可控条件下断网启动，并补测 WebView2 缺失、Windows 125%/150% DPI；无法提供环境时记录“跳过（待补测）”及原因。

### 6. M33：特殊凭证分组

使用 SH-A 检查第 18 页“贷款利息到期通知书”和第 26 页“电子缴税付款凭证”。确认应用能提醒存在非标准凭证，并允许按凭证类型及实际版式独立调整；同类型且实际版式一致时才允许批量同步。
