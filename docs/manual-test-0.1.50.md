# 银行回单工作台 0.1.50 定向人工复检单

本轮只验证版式微调预览、模板栏位提示及已排除片段的风险提示。以下均为**待远端 Windows 安装包人工验收**，源码测试和打包成功不能替代界面验收；已通过的其他项目无需整套重测。

## 准备

1. 覆盖安装或安装 0.1.50，启动后在“帮助与反馈”确认显示 v0.1.50。
2. 使用上海银行 SH-A（202510，26 页）的工作副本；仅在副本上建任务。开始前记录原件文件数量、字节数和 SHA-256，结束后复核。不得改名、移动、覆盖或删除 PDF 原件。
3. 选择“分割全部回单”并完成分析。先按实际内容处理特殊单证和无效空白片段；下述例子使用第 17 页第 3 栏的已排除片段。不同样本或已保存状态下的片段数量可以不同，应以界面实际变化数为准。

## 定向复检

### 1. 区分片段变化数、风险组数和模板栏位数

1. 在普通回单中选择第 1 页第 1 栏，进入“调整所选边界”，只对确实需要修改的第 1 栏调整边界，点击“确认并预览本轮”。
2. 检查标题是否明确为“检查本轮片段变化：…处”。例如本样本若仍显示 19 处，它代表本轮受影响片段，**不代表 19 栏**。
3. 在“保存为版式模板”旁检查是否显示“本轮可写入模板的栏位：1 / 3（第 1 栏）”及第 2、3 栏尚未核对。风险区的“已核对 … 组”只代表风险组，不能代替模板栏位核对。

预期：界面明确告知同一银行、同一凭证类型、同一实际版式的多栏只需一套整页模板；仅切换查看第 2、3 栏不会把它们计入本轮已核对栏位。

### 2. 已排除片段在保存前明确提示，撤销可恢复

1. 确认第 17 页第 3 栏原本为“已排除”。在第 1 步的预览中查找该位置；若本轮重算会使它转为“待复核”，风险列表须明确提示这一后果，即使它不在本轮片段变化列表内。
2. 不勾选该风险时尝试保存：应被阻止，且原已排除决定保持不变。核对风险后再次保存：此片段应转为待复核，由用户决定是否重新排除，不得悄悄变为可导出。
3. 撤销刚保存的本轮，确认原来的“已排除”状态恢复。若这一轮重算并未影响排除决定，应记录实际观察，不强行制造风险。

预期：保存前看得见状态变化，保存需要明确核对；撤销恢复排除决定。不要把风险勾选理解为“维持排除”。

### 3. 一套三栏模板与逐栏更新

1. 对确有打印留白或边界调整需求的普通回单，分别查看第 1、2、3 栏。如三栏都需要调整，可在同一整页编辑器内完成三栏调整，预览并核对后，**一次新建一套三栏模板**。
2. 若先保存了仅第 1 栏已核对的模板，后续第 2、3 栏确需调整时，分别从相应栏位进入，选择“更新已有模板”并明确指定同一模板；检查已核对栏位逐步累计为 2/3、3/3，而不是出现三套单栏模板。
3. 原边界正确、没有实际调整需求的栏位不应为了凑数而人为挪动。当前版本仅切换查看不会把它写为已核对；将此情况记录为现有交互限制。

预期：一套模板保存整页多栏定义，只复用已核对栏位。新建另一套模板不能意外覆盖现有模板，逐栏更新不能更改其他银行或其他凭证类型的模板。

### 4. 普通回单、特殊单证及原件隔离

1. 查看第 10、18、26 页的贷款/缴税等特殊单证，核对其类型、边界和审核状态；普通回单的微调与模板更新不应顺带修改它们。
2. 添加其他银行的同栏数样本，确认上海银行模板不会仅因同为三栏而自动套用。
3. 操作结束后比较原件数量、字节数和 SHA-256，确认与开始前一致；移除任务来源不删除磁盘原件。
