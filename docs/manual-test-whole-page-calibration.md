## 本次已查明的问题

- “82 处”是关键词命中的回单数，“31 处”是待复核回单数；原“50 页”是准备微调时纳入的版式页数，包含零命中页。
- 真实民生 161 页样本在纯 Core 环境复现原范围为 50 页。160 张三栏页的前两栏相同，仅第三栏底边最多相差 1 PDF point（约 0.35 mm），原精确版式 ID 比较过严。
- 修复后对已有安全几何数据重分类，范围为第 1—160 页；第 161 页实际两栏，继续单独处理。这是版式范围复验，并未复现用户具体关键词对应的 82 个命中。
- `201.44 + 96.25 = 297.69 mm`，超过 `297.04 mm` 页高 `0.65 mm`。三栏高度之和不能替代每栏“距页顶 + 高度”的检查。
