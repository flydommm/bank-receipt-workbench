## 开始前

- 关闭工作台，从当前已装版本按默认目录覆盖安装，保留数据；在“帮助与反馈”确认版本为 0.1.43。
- 使用已有测试副本：HX-A（671 页）、HX-B（111 页）、MS-B（161 页）、SH-A（26 页）。本轮至少准备两份，其中一份为 SH-A；输出选择独立目录。
- 整轮开始前记录输入副本的文件数量、字节数和 SHA-256，结束后统一再核验一次。测试中移除来源、排除片段均不应修改磁盘原件。
- 记录 Windows 版本、屏幕分辨率和系统缩放；发生问题时记下来源代号、页码、栏位、当前筛选和操作。

## 1. 缩略图浏览与详情返回

1. 新建任务，加入 HX-A 和另一份 PDF；不分析，在两份来源间切换“原页总览”和“单页”，核对页数和页码。
2. 在原页总览连续向下滚动并调大、调小缩略图；检查画面随滚动更新，没有串入另一文件的页面，也没有横向溢出。
3. 选择“不输入关键词，分割全部回单”并分析。切换“片段总览”和“原页总览”，抽查首、中、尾页及单栏、双栏尾页；片段缩略图应只展示其自身边界。
4. 从中间位置打开详情，操作上一项、下一项，再返回总览；应返回相应浏览位置。原页总览应保留无候选页，该页不能选中不存在的片段。

**通过标准：** 预览内容、页码和框位对应正确；滚动、缩放、来源切换可用；打开详情再返回不必从头寻找。

## 2. 多选范围、确认、排除和恢复

1. 按来源、凭证类型及“待复核”筛选，先勾选两三项，再用 Shift 连选、全选当前筛选结果；核对数量包含离屏项，且不包含筛选外项目。仅勾选不应改变审核状态。
2. 改变筛选后，旧选择应清空。在小范围内重新选择可接受的待复核项并确认；应只确认这些项，各项原边界不变。标为“需调整”的问题不能直接确认绕过。
3. 勾选两三项测试片段，点击“排除所选 N 处”；只排除所选项，其他来源、类型与未选项不变，原件保留。
4. 切到“已排除”，选择刚才的片段并恢复；应重新变成待复核，不自动恢复为已确认。原页卡的勾选范围只包含本页符合当前筛选的候选。

**通过标准：** 选择数、操作数和实际变化一致；全选范围明确；确认、排除、恢复互不混用。若出现错误，不应把未成功的项目显示为已成功。

## 3. 特殊单证、普通回单与微调隔离

1. 使用 SH-A，分别筛选普通回单、贷款利息到期通知书和电子缴税付款凭证；打开详情核对第 18 页通知书及第 26 页缴税凭证。有效特殊凭证不应自动排除。
2. 选一个需要改边界的片段，打开“调整所选边界”；先查看本轮实际影响的银行、类型、版式与页数。总览勾选范围不等于版式同步范围。
3. 微调后按“确认并预览本轮 → 核对风险 → 保存本轮 → 完成微调，返回结果”执行。抽查同类型、同版式对应栏位，以及另一类型、另一银行；前者按显示范围更新，后者不应被覆盖。
4. 普通回单与特殊单证分别确认，核对彼此待复核数量和边界不变。可以优先处理特殊或边界问题，但正确隔离不应依赖操作先后。若测试撤销，核对只恢复该轮调整。

## 4. 阶段按钮与完整导出

1. 依次观察“导入分析 → 检查处理 → 预览导出”。未选择项目时不出现批量操作；选择后才显示对应操作；详情中的操作只作用于当前片段。
2. 尚有未排除的待复核项时，不应显示“预览并导出”。确认或排除完后应出现；再恢复一个已排除项，导出入口应重新隐藏。
3. 重新处理完待复核，保持一个较小的总览筛选并进入导出。导出设置的数量必须等于全部未排除项，不能只导出当前筛选或勾选项。
4. 生成预览，选择独立输出目录并导出；核对 PDF 内容和数量，开启 XLSX 时核对其明细不含排除项。移除一个来源，确认磁盘文件仍在。
5. 统一复核输入副本的文件数量、字节数和 SHA-256，与整轮开始前保持一致。

**通过标准：** 操作按阶段出现；待复核清零才可导出；导出所有保留片段，排除项不进入 PDF/XLSX 明细；原件保持不变。
