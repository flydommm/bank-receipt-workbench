# 模板工作流修复与定向验证（2026-09-22）

本轮依据 [0.1.41 远端实测记录](manual-test-0.1.41-remote-2026-09-22.md) 完成模板工作流源码修复和工程验证，并纳入 0.1.42。新安装包只需执行[四项定向复检](manual-test-0.1.42.md)；旧安装包的失败项保留原始记录，不改写为人工通过。

## 修复内容

| 问题 | 修复行为 |
| --- | --- |
| 选择另一模板后名称框仍显示旧名称，重开时可能为空 | 名称草稿与模板 ID 绑定；异步载入、切换、刷新与重命名完成时同步更新，写入期间禁止切换，防止把旧名称保存给另一模板。 |
| 取消统一高度、只更新一栏时，边界已保存但模板失败 | 将“统一高度”视为编辑约束；局部更新允许各栏高度不同，只替换本次已核对位置，并保留此前已核对位置。合并后仍检查重叠和页面范围。 |
| 模板失败后一律提示重试 | 区分真实共同边距变化、合并后几何冲突、停用或撤销、数据校验、暂时存储失败；仅暂时写入失败提供重试。审核保存成功与模板保存结果分别报告，错误返回不包含内部路径。 |
| 新任务沿用旧审核结论，停用模板后仍可能沿用源文件旧框位 | 新任务只从可用模板复用已核对边界；不恢复其他任务的审核结论，也不从旧来源校准记录绕过模板停用。当前任务的刷新、继续、保存和撤销按任务隔离。 |
| 未确认栏位及停用后的隔离证据不足 | 补充独立临时库中的回归：未确认栏位不复用、不自动确认；连续局部更新保留原有确认来源；停用整个模板族后重开库无旧版本回落，显式保存的新版本仍可用。 |

模板保存的“已核对栏位”表示这些边界可供新文件参考，不代表新文件内的回单内容已审核。新分析可以复用边界，但复核提示仍依据本次分析产生。

## 0.1.42 安装包只需定向复检

1. 打开“我的模板”，在两份模板间切换、刷新、关闭后重开，确认名称输入框与当前标题一致。重命名后另一模板名称不变。
2. 对已保存三栏模板取消统一高度，只缩小首栏高度，核对并保存为模板；确认新版本首栏更新，其他已核对栏位保留。另建仅确认首栏的模板，确认第二、第三栏仍显示未核对，并且新分析不套用它们。
3. 使用同一 PDF 分别创建两个任务，确认第一个任务后再分析第二个；第二个不能直接继承已确认状态。两个任务先后保存或撤销不覆盖彼此结果，已由隔离临时库的自动化回归核验；人工复检无需重新打开历史任务。
4. 停用目标模板族后重新分析同版式 PDF（包含之前已处理过的样本），确认没有使用停用模板或旧来源校准。已在进行中的任务保留原快照；显式重新保存可创建新版本。

这些步骤只覆盖本轮修复，不重跑已经通过的安装、离线、缩放、导入与原件保护测试。
