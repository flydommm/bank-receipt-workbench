## R01 换关键词保留已保存的整页三栏边界（M07 补充）

1. 导入民生银行 161 页测试副本，按原测试关键词搜索。本次本地副本不含完整的“KW-C-FULL”，自动回归使用实际存在的“KW-C”，得到 82 个命中；人工测试可采用同一关键词。
2. 在结果里选三栏页面，例如第 18 页第 1 栏，进入“调整所选边界”。分别放置三个框，输入统一高度；记录每栏的距页顶、回单高度与左右边距。
3. 点击“确认并预览本轮”，检查后核对所需项目，显式保存本轮；导出一份 PDF 作为比较依据。
4. 返回分析，保留同一来源，把关键词改为“KW-B”并重新分析。
5. 抽查第 3、5、18 页及其他共同命中页的首、中、尾栏；还要检查第一次未命中、第二次才命中的回单。进入编辑器核对数字后返回，勿重复保存掩盖问题。
6. 改为另一个存在的关键词再查，并切换至“分割全部回单”。关闭应用重新打开后再重复一次换词操作。

预期：候选集合随关键词变化，已保存的适用页面几何保持一致；不会恢复为刚上传时的自动框。新结果按当前关键词重新筛选，不复制旧关键词或把所有新命中自动标记为已人工确认。两栏尾页等未纳入该轮的页面维持自己的布局。

补充：未保存的草稿不得影响重查；撤销已保存轮次后新建分析不得继续使用被撤销的调整；另一份内容不同的 PDF 即使同名，也不得套用本次页面边界。

## R02 切换处理方式后原件预览与分析入口可用

1. 导入 PDF 并完成关键词分析，再返回分析。
2. 切换至“不输入关键词，分割全部回单”，点击左侧 PDF 文件名。
3. 翻页、缩放，启动全部分割，检查数量及结果来源。
4. 返回并切回关键词模式，核对原关键词保留；输入新关键词再分析。
5. 另起任务，导入大 PDF 后立即开始分析；完成并返回后，重复上述切换。

预期：来源保留，页数正确，可以预览并启动新模式分析；旧“分析完成”和“查看任务结果”不会占用新模式的入口；无需移除再上传。若切换时出现未保存修改确认并选择取消，原结果、模式与输入应保持原样。
