# 版式模板使用说明

本说明对应 0.1.41 Core x64 NSIS，描述版式模板工作流的边界和使用方式。安装包构建、安装和人工定向复验结果以 0.1.41 定向复验单（历史资料已归档） 及交付记录（历史资料已归档）为准；本说明不把源码行为写成人工通过结论。

## 保存已核对的边界

1. 添加 PDF 并分析，选中要保存的回单，打开“调整所选边界”。
2. 检查对应栏位的位置和高度；原来的边界正确时可以直接进入本轮预览，无需为了保存模板而改动数字。
3. 核对本轮结果，勾选“保存为版式模板（已有同版式时更新）”，填写便于识别的名称，例如“民生银行普通回单三栏”。
4. 点击“保存本轮”。保存成功后会分别显示审核结果和模板保存结果；模板写入失败时可以单独重试。随后依次点击“完成微调，返回结果”和“返回分析”，回到分析/来源阶段，再打开“我的模板”查看保存结果。

模板只信任本轮及此前已核对的栏位。没有核对过的其他栏位不会自动成为可信边界。在“我的模板”里，已核对栏位显示绿色实线，未核对栏位显示灰色虚线。

## 在新文件中使用

- 默认显示“版式模板：自动匹配”。开始分析后，应用根据出具银行、凭证类型、实际版式、页面尺寸与方向和栏位位置寻找可用模板。
- 若要指定模板，在分析前点击“我的模板”，查看框位与参数，然后点击“选用此模板”。分析区会显示模板名称和版本。可点击“改为自动匹配”取消指定。
- 手动选择同样需要通过匹配检查，不会强行把其他银行或其他凭证类型的框套到当前 PDF 上。
- 模板只提供边界。关键词命中、当前文件的内容以及是否需要复核都会重新计算，不继承旧任务的关键词结果或审核结论。尾页只有一栏或两栏时，只应用实际存在且位置对应的已核对栏位。
- 已经得到分析结果后更换模板，需要重新分析。

模板保存在本地数据中，应用重启后仍可在“我的模板”查看和使用；重启不会改变银行、凭证类型和实际版式的匹配限制。

## 查看、更新和停用

“我的模板”入口位于分析/来源阶段。微调、审核或导出阶段不显示该入口；保存后依次点击“完成微调，返回结果”和“返回分析”，再打开“我的模板”。模板管理页提供名称、版本、状态、框位示意和毫米参数。可以重命名；需要更新边界时，在 PDF 中重新微调、核对并保存，同版式生成一个新版本。之前已核对且仍处于合法位置的栏位继续保留；其他未核对栏位不会因为保存新版而被自动认可。

“停用此版式”会停止整个版式族在后续新分析中的匹配，新分析不会回落到旧版本。勾选“显示已停用模板”可查看停用记录。已经开始分析的任务使用当时固定的模板快照，不被其后的更新或停用改变。

应用不再提供“历史任务”入口。原有任务记录不自动删除，也不自动转换为模板；原始 PDF 保持只读。
