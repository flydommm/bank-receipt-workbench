# 回单总览与阶段化处理说明

本说明对应当前源码中的三阶段流程：**导入分析 → 检查处理 → 导出文件**。原始 PDF 只读，审核和处理结果保存在当前任务中。默认“分割全部回单”、贷款清算通知书识别、人工凭证分类、特殊单证核对与混排单栏隔离属于 0.1.45 本轮修正。

> 0.1.45 在 0.1.44 的原页总览、片段检查和导出设置基础上，补充特殊单证分类和人工边界隔离；历史发布记录不随本说明改写。安装后的人工验收以 [0.1.45 定向复检单](manual-test-0.1.45.md) 为准。

## 1. 导入分析

选择 PDF 或文件夹后，默认先在源 PDF 预览的“原页总览”中熟悉材料。分析前可以在“原页总览”和“单页”之间切换：原页总览每张卡对应一页，单页模式可以按页查看；“缩略图大小”用于调整总览的查看密度。新任务默认“分割全部回单”；需要关键词时切换“查找提取回单”。当前任务已明确选择的方式在追加来源时保留，分析完成进入“检查处理”。

## 2. 检查处理

结果页默认显示“片段总览”，每张卡对应一个候选片段。切换到“原页总览”后，每张卡对应一页，包括没有命中片段的页面；没有命中的页只供查看，不能选择不存在的候选。总览工具可以切换片段/原页视图，并调整缩略图大小。

总览提供三类筛选：

- 来源 PDF；
- 凭证类型，包括普通/未标记特殊和已识别的特殊类型；
- 片段状态，包括全部、待复核和已排除。

勾选只表示选择对象，不会改变审核状态。“全选当前筛选结果”会选择当前筛选命中的全部片段，包括暂未渲染或在视口外的卡片。切换来源、凭证类型或状态筛选会清空已选对象。原页卡勾选时，只选择本页符合当前筛选的候选。

界面提示“单选后可微调边界，多选后可批量处理”。待复核筛选为空但仍有已确认片段时，可以点击“切换到全部，继续调整已确认片段”明确回到全部筛选；应用不会静默改变筛选条件。

选中片段后，可以执行以下批量操作：

- “确认所选 N 处”：确认可确认的待复核片段。每条记录保留自己的边界；标记为“需调整”的片段不能确认，也不能通过普通确认绕过边界或版式问题。
- “排除所选 N 处”：将片段标记为已排除，不删除原始 PDF。排除项仍保留在当前任务中，也不会进入导出结果。
- “恢复所选 N 处为待复核”：将排除项重新纳入审核。恢复后必须重新检查，不能直接当作已确认。

打开单张详情后，可以“返回总览”、使用“上一项/下一项”切换卡片，并对当前片段执行“确认此片段”“调整所选边界”或“排除此片段”。“确认此片段”和“排除此片段”只作用于当前片段；已确认片段单选后也可以“调整所选边界”，微调界面会展示实际的同版式范围。检查时确认抬头、正文、印章和底部内容完整，没有带入相邻回单。

## 3. 必要时微调边界

边界正确时可以继续后续处理；希望统一打印尺寸或修正边界时，单选一个片段或打开详情后使用“调整所选边界”。自动候选和已确认片段都可以微调，并继续使用整页栏位编辑器和本轮预览、保存、模板及撤销流程。

微调范围严格按同出具银行、同凭证类型、同实际版式的页面确定。勾选了多少片段不等于版式同步范围；打开版式调整后，界面会显示本轮实际的 PDF、页面和命中数量。不同银行、凭证类型、实际版式或页面几何不互相同步。

编辑器以整页栏位为单位，可以调整栏位距页顶、回单高度和左右边距。复制/粘贴只复制高度；“统一所有栏位高度”会统一高度，保留每个栏位原来的顶部位置，不会把栏位顶部强行对齐。

调整完成后按这个顺序操作：

1. 点击“确认并预览本轮”。预览会显示本轮实际候选、变化和风险，尚未直接保存。
2. 逐项检查风险并勾选确认；存在阻断问题时本轮不能保存。
3. 点击“保存本轮 N 处”。可以同时勾选保存为版式模板，并填写模板名称。模板只供同银行、同凭证类型、同实际版式的新文件参考，不继承旧任务的审核结论。
4. 保存完成后点击“完成微调，返回结果”，或继续处理下一位置。已保存的轮次可以使用“撤销本轮”恢复本轮调整前的边界和复核状态。

如果界面提示保存或撤销结果待核实，点击“核实并完成保存”或“核实并完成撤销”，让应用检查实际保存结果后继续。此时按界面提示操作即可，无需重复保存或撤销。

## 4. 导出文件

所有未排除的待复核片段清零后，检查处理阶段才会显示“导出回单”。进入“导出设置”后：

1. 编辑“导出名称”。单来源时，全部回单模式默认使用“原件名 + 全部回单”，关键词查找模式默认使用“原件名 + 关键词 + 查找结果”；多来源时用“多来源 + 文件数”标识这批文件。名称可以修改，文件夹还会附加导出时间和防重名后缀。
2. 选择“导出方式”：合并为一个 PDF、按来源分别导出 PDF，或同时导出两种 PDF。
3. 按需勾选“同时导出 XLSX 索引”；“同时导出清单 JSON”默认不勾选，需要时再开启。
4. 点击“选择目录并导出”，选择目录后直接完成本次导出。流程没有单独的生成预览或最终预览步骤。

导出范围固定为当前任务中的全部未排除项，包含自动候选和已经确认的保留项；已排除项不进入 PDF 或 XLSX。总览中的来源、类型和状态筛选只影响查看与选择，不会缩小导出范围。写入失败时点击“重试导出”，应用会复用同一次导出和已选目录，避免重复生成文件。成功后可以点击“移除本次来源”；已导出的结果保留。

## 5. 特殊单证

当前自动识别根据页首标题等规则提示三类特殊单证：

- 贷款清算通知书；
- 贷款利息到期通知书；
- 电子缴税付款凭证。

也可以单选或多选片段，通过“设置凭证类型”补充或纠正分类，包括“普通回单”“其他特殊单证”及上述三种类型。人工分类只影响明确选中的片段，同页其他栏位不会被一起改类型。

建议按以下顺序处理：**特殊单证与排除项 → 普通回单及模板 → 导出**。

1. 分析后点击“来源与类型”中的“核对特殊单证 N 处”，查看当前来源内仍待复核的特殊单证。自动识别漏掉时，可从全部结果选择片段，使用“设置凭证类型”。
2. 分类面板显示实际选择数量，默认只确定类型并保留待复核。只有勾选“类型与边界均已核对”才同时完成审核。检查抬头、正文、印章和底部，不能把设置类型当作已经检查边界。
3. 边界需要调整时，先保存类型，再“调整所选边界”，核对实际影响范围，预览并保存。自动类型已正确、边界也完整时，仍可直接“确认此特殊单证”或“确认所选特殊单证 N 处”。
4. 确实不需要导出的片段可以排除；排除和特殊分类是独立操作。已排除项需要先恢复，阻断项需先修正，不能通过分类绕过。
5. 再处理普通回单，需要统一打印尺寸时微调和保存模板；最后未排除的待复核清零后导出。

普通确认认可当前边界，保留原有类型；改回普通回单须在类型面板明确选择。类型变化后只设置分类会重新待复核，已打开的旧微调预览或导出范围不能继续使用。

没有人工覆盖的自动特殊单证仍按同银行、同凭证类型、同实际版式分别调整和使用模板。隔离不依赖谁先确认；已确认状态本身也不是禁止后续微调的锁。

人工分类的页面会退出普通回单的跨页批量同步。该页微调仅限当前选择的栏位，其他栏位、公共左右边距和统一高度被保护；要调整同页另一栏，返回结果重新选择它。人工类型本身不足以证明跨文件版式，因此这类轮次不保存可复用模板。“其他特殊单证”不表示它们彼此属于同一种版式。

设置类型不会把片段自动扩大为整页，也不会把误拆的两块合并成一张。发现结构误拆时，不应勾选完整性核对；本轮分类功能不包含任意合并或重建分割结构。自动识别仍是有限规则，人工核对用于补充和纠正识别结果。
