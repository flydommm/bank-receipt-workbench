# 银行回单工作台 0.1.48 定向人工复检单

本轮只复检 0.1.48 的版式模板生命周期和隔离规则，不重新执行已经完成的 M01-M35 全套测试。2026-09-24 已通过 UU 在远端干净 Windows 的 0.1.48 工作台执行下述定向复检，结果见本文末表和 [远端复检记录](acceptance-0.1.48-remote.md)。本文件不把工程测试结果写成 GUI 通过结论。

## 测试准备

- 覆盖安装 0.1.48，保留用户数据；在“帮助与反馈”确认显示 v0.1.48。
- 保留既有模板，打开“我的模板”确认旧模板和历史版本仍可见；不得出现“历史任务”入口替代模板入口。
- 仅使用 PDF 工作副本。复检前后记录副本文件数量、字节数和 SHA-256，原始文件保持只读，不在原目录改名、移动、覆盖或删除。
- 样本按“同一家银行、同一实际版式”“其他银行同栏数版式”“普通回单”“特殊单证”分别准备。上海银行样本若仍无法可靠确认跨文件身份，只验证隔离提示，不能把它记为跨文件模板通过。

## 定向复检

### 1. 安装、旧模板和新任务隔离

1. 覆盖安装 0.1.48，保留数据并启动；记录帮助与反馈版本。
2. 检查旧模板的名称、银行标签、版本和启用状态；关闭应用后重新打开，确认数据仍在。
3. 使用同一银行样本新建任务，设置本次任务的处理方式和搜索条件后重新分析；确认分析按当前选择的关键词和搜索条件执行，历史关键词可以保留供用户选择，但上一任务的排除、特殊单证分类和审核勾选不被带入新任务。

预期：旧模板保留，任务状态不冒充模板状态；所有观察结果记录为“待测试/通过/失败”。

### 2. 同一银行保存两套独立模板

1. 分析同一银行、同一凭证类型、同一实际版式的工作副本 A，调整第 1 栏边界，确认本轮结果，选择“保存为版式模板”，使用名称“常用版”，保持“新建一套模板”，保存。
2. 在相同范围再次调整为另一组留白或高度，保持“新建一套模板”，保存名称“紧凑版”。
3. 打开“我的模板”，确认同一家银行下同时存在“常用版”和“紧凑版”，两者都从 v1 开始；分别查看边界和已确认栏位，确认尺寸没有互相覆盖。

预期：同银行可以多套并存；不按公司拆分，也不因同为单页三栏而合并；同一银行不同公司的相同实际版式可以复用，但版式或留白不同可以另建模板。

### 3. 指定更新与部分栏位

1. 选择“常用版”，明确切换到“更新已有模板”，只调整并确认第 1 栏，保存。
2. 检查版本号：只有“常用版”递增，且只改变目标栏位；“紧凑版”的名称、版本、边界和启用状态保持不变。
3. 查看未确认的第 2、3 栏，确认没有被自动扩大为已确认，也没有因同银行或同栏数被批量写入。

预期：更新必须指定目标；保存失败、目标被停用或版本过期时，不覆盖旧版本，应提示刷新或重新选择。

### 4. 多套匹配、手动选用和重分析

1. 添加可同时匹配“常用版”和“紧凑版”的新文件，开始分析。
2. 确认界面提示存在多套适用模板，不静默套用最新模板、不混合两套边界；允许继续核对当前自动边界。
3. 手动选择“紧凑版”，确认后重新分析；检查本次只使用“紧凑版”的边界，并重新生成本次任务的审核状态。

预期：候选不明确时由用户选择；重新分析后只使用所选模板边界，审核勾选、排除和人工特殊分类按新任务初始状态建立；关键词按当前任务的处理方式和搜索条件执行，历史关键词仍可作为可选项。

### 5. 改名、停用和恢复隔离

1. 将“紧凑版”改名，确认“常用版”名称不变。
2. 停用“紧凑版”，新建任务重新分析；确认停用模板不再自动匹配，仍启用的“常用版”不受影响。
3. 如界面支持恢复，恢复“紧凑版”后再次检查；如不支持恢复，记录为产品行为，不手动改库。

预期：改名、停用、恢复只作用于目标模板；旧版本和另一套模板不被删除或改写。

### 6. 银行、凭证类型和身份隔离

- 添加其他银行的同栏数 PDF，确认不能套用前一家银行模板。
- 添加同一家银行的不同实际版式，确认不能只凭银行名或栏数套用。
- 将普通回单与“贷款利息到期通知书”“电子缴税付款凭证”等特殊单证分开审核；特殊单证可单独微调、确认或排除，不改变普通回单模板。
- 对身份无法可靠确认的 SH-A，确认系统不因用户填写银行名称就生成跨文件模板或假装已修复识别；记录提示和可用的本轮保存行为。

### 7. 模板复用后的原件完整性

1. 在模板选择、重分析、审核和导出预览前后，核对工作副本的文件数量、字节数和 SHA-256。
2. 确认“移除来源”只从任务移除文件，不删除磁盘原件；模板操作不修改原件。

预期：原件前后一致，导出写入独立输出目录；发现差异立即记录文件名、阶段和哈希，不继续覆盖原件。
