# 0.1.57 发布说明

0.1.57 是银行回单工作台的 Windows x64 Core 公开预发布。本版从已脱敏的公开源码构建，安装包未签名；当前发布只包含 Core，扫描型 PDF/OCR 不在本版安装范围内。

## 用户可见变化

本版把回单处理固定为三个清晰阶段：**导入预览 → 分析处理 → 导出结果**。

- 添加 PDF 后默认进入原页总览，并默认选择“分割全部回单”；需要关键词时可以切换为“查找提取回单”。
- 原页和片段都提供缩略图总览、滚动、缩放、来源/类型筛选以及当前筛选结果的多选批量处理。
- 疑似需排除片段可以独立查看、批量排除或恢复。排除只作用于当前任务和导出范围，不删除磁盘上的原始 PDF。
- 贷款通知书、缴税凭证等特殊凭证可以在分析结果中单个或批量确认为特殊凭证，并与普通回单分开审核。
- 普通回单可以按所选栏位微调边界。单栏微调只影响明确选中的栏位；受影响的片段会重新提示复核。
- 版式模板按银行管理，同一家银行可以同时保存多套模板。模板可查看、更新和停用，只复用已确认的边界；新任务不会继承旧任务的审核、排除或特殊凭证状态。
- 当前入口不再保留“历史任务”；需要复用处理经验时，请使用“我的模板”中的版式模板。
- 待复核全部处理完成后直接进入导出设置。可导出合并 PDF 或按来源拆分的 PDF，XLSX 索引可选，清单 JSON 默认关闭。

## 修复内容

- 修复排除项与单栏微调之间的隔离：不受影响的已排除片段保持排除；真实边界变化影响到相邻片段时，系统只对受影响范围重新提示复核。
- 修复浙商银行等同一页多栏版式的身份核验，避免版式身份不足时错误保存可跨文件复用的模板。
- 修复大批量候选在重新打开检查轮次后的缓存回归测试超时，保留原有真实流程和逐项顺序断言。
- 公开安装包移除编译机绝对路径等构建环境信息；最终资源核验和 Release 资产清单以本版发布记录为准。

## 下载与校验

最终安装包、源码归档、构建记录、第三方许可材料和 `SHA256SUMS.txt` 均以 [GitHub Release v0.1.57](https://github.com/flydommm/bank-receipt-workbench/releases/tag/v0.1.57) 的 Assets 为准。公开安装包名称为：

`bank-receipt-workbench_0.1.57_core_x64-setup.exe`

下载后请使用发布附件中的 `SHA256SUMS.txt` 核对文件，不要使用本地 `outputs/` 中的中间产物。安装包未签名，Windows 可能显示来自未知发布者的提示。

## 验证边界

GitHub Actions 自动检查必须在发布前通过；具体运行链接和最终源码提交记录在 GitHub Release 正文及随包 `build-info.json` 中。源码测试、运行时资源核验和本机构建不替代干净 Windows 安装验证。0.1.57 新安装包的安装、升级、卸载、WebView2、DPI、导出完整性和模板隔离，应按[发布清单](release-checklist.md)逐项复核；在这些证据完成前，本版本保持预发布状态。
