# 按交易对手整理回单

本文对应 0.1.62。完整导入、审核和导出步骤见[使用指南](usage.md)。

## 本批账户

一批材料对应一个公司、一个来源银行和一个完整本方账号，可同时导入该账户多个期间的 PDF。来源银行是回单出具银行，对方可以在其他银行开户。本公司不同账户之间的往来保留在内部往来组。

启用整理默认进入“选择本机档案”。本机档案可手工新增，也可下载内嵌 Excel 模板批量导入。预览完整显示每行资料和判定结果；只导入有效行，重复行跳过，错误行修正后重新导入，不覆盖已有档案。账号按文本保存，保留前导零。

清除或更换来源后必须重新选择本批账户，仍默认打开本机档案模式。更正已开始任务的本方资料应使用“更正本批资料并重新分析”。档案编辑或停用不会改动已开始任务的资料快照。

## 日常核对

先完成分割审核，再进入分组并等待提取。左栏筛选组别，中栏查看或勾选回单，右栏对照原件；搜索和切组会清除勾选，每批最多 200 张。

- **交易对手组**：按当前对手名称归组，名称相同默认同组，但不能据此证明是同一主体。
- **本公司内部往来**：按本批公司统一归组，不因对方账户银行不同而拆组。
- **对方名称为空**：原件没有对手名称，可单独批量处理。
- **对手待确认**：名称读取或本方归属存在疑点，需要核对，不能与空白混同。
- **特殊凭证、已排除**：保留各自处理方式；已排除内容不进入 PDF。

选单张或勾选多张后，点击“修改交易对手”，可直接输入名称或选已有名称，不要求判断付款/收款方向。输入后使用编辑区的“保存所选 N 张”，取消不改动结果。已自动分组的名称也能批量修改。

手续费、结息、税款等票面没有对手名称时，可以确认“原件确实没有交易对手名称”，也可按需要分别命名；不要把本方或摘要错误填成对手。同名实际不同主体时，核对账号等依据后用更多工具拆组。原始识别字段保留供回查。

## 同版式批量识别与本机规则

“修改交易对手”直接修正本批结果；同版式批量识别用于修正读取位置并重新读取多张回单，两者用途不同。

1. 在更多工具中打开同版式批量识别，在原件框出本方及对手名称，不需要选择收付款方向。
2. 默认试读本批待确认回单，也可包括自动识别结果；跳过已人工修正、已排除和特殊凭证。
3. 查看每张的原名称、试读名称和处理结果，可按名称汇总检查；读不清的仍待核对。
4. 核对后应用。需要下一批复用时，勾选保存为本机读取规则并命名。

同版式左右位置可能互换或双方同名时，可补充另一处名称或对应账号帮助判断。原件没有名称的费用或利息单直接确认空白或手工命名，不必强行设置读取位置。

规则只保存位置和匹配约束，不保存本次对手名称；下一批重新读取每张名称，不自动覆盖人工修正。停用只影响之后的自动匹配，不改已经整理的回单。本机规则不同于版式模板：前者读取字段，后者裁剪页面。

诊断摘要和原始字段位于更多工具，用于排查不认识的版式；日常处理只需选回单、改对手、检查并导出。

## 核对草稿与正式导出

提取完成并载入分组结果后，可提前导出核对草稿 Excel。草稿保留待确认原因、人工修正和来源信息，不表示正式导出已通过；不支持修改草稿后回导。

“检查并导出”支持：
- **每组一个 PDF**：每个组一份，纳入的待确认项单独存放。
- **合并为一个PDF**：所有保留片段合为一份，各组连续排列，待确认项放在最后。

应用记住上次导出方式。两种方式均生成总核对表，JSON 按需选择。存在待确认项时先修正或明确纳入导出，不能只导出其他组而静默遗漏。未完成字段提取、分割审核或失败来源仍需先处理。

总核对表记录来源文件、页、栏位、分组、输出文件及输出页码；排除项另列。组内保持来源、原页和栏位顺序。每个保留片段恰好一个去向，同页相同范围可能合为一页，因此片段数和页数可能不同。按组单次最多 501 个 PDF，超过时提示，不会仅导出部分组。

进度面板显示当前阶段及已用时间；有计数的阶段显示完成量与阶段百分比，PDF 写入或校验等未知阶段显示持续活动。每次输出新目录，不覆盖旧结果。失败时按提示重试，暂存文件不能当作正式完成文件。

当前 Core 面向文字 PDF，不含扫描件 OCR、不做账务核算、跨文件交易去重或跨批学习对手别名。陌生版式保留待确认，让用户对照原件处理。
