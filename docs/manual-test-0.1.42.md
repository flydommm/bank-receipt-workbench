### 2. 合法局部更新与未确认栏位

**前置条件：**准备一个同实际版式、已保存三栏边界的模板和测试副本；对另一银行或另一实际版式准备尚无可用同版式模板的样本。完成分析后进入结果检查，再点击“调整所选边界”。

**步骤：**

1. 取消“统一高度”，只缩小首栏到仍不重叠且在页面范围内的合法高度；核对首栏并保存为版式模板的新版本。
2. 查看新版本，确认首栏边界更新，第二、第三栏此前已核对的边界仍保留。
3. 对尚无可用同版式模板的另一银行或另一实际版式样本，只核对首栏并保存为版式模板；再用同实际版式的新 PDF 分析，确认第二、第三栏显示未确认，且新分析不会把它们自动确认或套用为已确认结论。
