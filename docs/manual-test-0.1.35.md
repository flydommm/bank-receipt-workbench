## 优先复测

### M05 / M06：导入与预览速度

1. 新建任务，加入 HX-A；**不开始分析**，确认第一页、翻页和缩放可用。记录首次显示、返回已看页面的体感时间。
2. 加入另一份测试 PDF，在来源间快速切换；分别在原件预览和分析结果中连续点选不同页/片段，再停在最后一项。
3. 确认最终显示跟随最后选择，没有停在较早的页或片段；返回刚看过的页面可正常显示。移除来源只影响任务，不应删除磁盘原件。

**通过条件：**页面与片段切换正确，无永久空白或旧页覆盖。M05/M06 的功能部分已有本轮通过反馈；速度单独记录冷启动首次预览、回看和连续切换的实际体感，不能用功能通过掩盖性能问题。本机性能数字不作为干净系统通过标准。

### M07：关键词与三栏统一高度

1. 用 HX-A 新建任务，输入测试记录中 **KB-A 所对应的实际关键词**，开始分析。
2. 选择普通三栏回单，进入整页微调，将三栏距页顶设为 **3.22 / 101.29 / 199.01 mm**，统一栏高设为 **96.94 mm**，确认并预览本轮。
3. 记录从点击确认到预览完成的时间；若失败，记录完整提示并确认草稿是否保留。避免只凭进度数字判断卡死。

**通过条件：**预览能完成；不在约两分钟时因操作超时失败。页数、结果和待处理状态可继续查看。此为 671 页整批重算，长时间运行时记录耗时和最终状态。当前 HX-A 与 MS-B 的干净系统用时明显高于本机，仍在进行中，不能仅凭耗时判定功能失败。

### M19：同栏风险合并、全选与导出范围

1. 在本轮检查列表定位 HX-A **第 670 页**：第 2 栏命中，检查第 2、3 栏风险。界面应按“来源、页、栏”分组。
2. 同一栏的多条风险应合并为**一个核对行、一个复选框**，行内可显示风险条数；本轮结果中的栏位与“仅做版式核对”的栏位应能区分。单独确认第 3 栏后，该组风险应一次全部确认。
3. 测试单选、Shift 连选、全部标为已核对，再取消全选；检查已核对数量和保存按钮状态。用新建的空输出目录做小范围导出，确认未命中栏位不会因此加入导出结果。

**通过条件：**同栏只需勾选一次；全选/取消与计数一致；核对版式风险不扩大关键词命中或导出范围。
