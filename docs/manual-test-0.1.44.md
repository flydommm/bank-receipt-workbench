# 银行回单工作台 0.1.44 定向复检单

目标：0.1.44 Core x64 安装包。本轮只复检回单总览、阶段化操作和导出流程的改版内容，不要求用户从 M01 重新跑完整套安装、卸载、环境与性能测试。以下人工结果均待测；源码自动化、合成界面和打包资源检查不能代替安装后的人工验收。

0.1.43 尚未完成的模板项目可以直接在本轮补做并记录；旧版本的已通过结果继续作为历史证据，不改写成 0.1.44 的人工通过。

## 开始前

- 安装或覆盖安装 0.1.44，确认“帮助与反馈”显示 `v0.1.44`。保留用户数据时，不要求清理历史数据；本轮不使用旧历史任务作为可恢复任务。
- 准备 HX-A（671 页）、HX-B（111 页）、MS-B（161 页）和 SH-A（26 页）测试副本。至少准备一份三栏普通回单和一份包含特殊单证的副本；所有副本放在独立输入目录。
- 测试开始前记录每份原件的文件数量、字节数和 SHA-256。导出、移除来源、排除片段和取消目录选择均不应修改输入目录中的原件。
- 记录 Windows 版本、分辨率、系统缩放和安装包 edition。每一项记录来源代号、页码、栏位、当前筛选、操作前后数量和截图路径。

## 1. 导入后默认总览与处理方式

1. 新建任务，添加一份 PDF，等待文件读取完成。确认中间区域默认进入“原页总览”，而不是单页模式；缩略图对应真实页码，能看到没有命中片段的页面。
2. 在“原页总览”和“单页”之间切换，再切换到另一份 PDF，确认当前来源和页数随来源更新。返回新加入的来源后，默认视图不应串入上一份文件。
3. 检查右侧选项顺序和文字：第一项为“分割为全部回单”，第二项为“查找提取回单”。页面不应再显示独立的“处理方式”标题；两项仍应有清晰的可访问名称和互斥选择状态。
4. 分别选中两种处理方式但先不分析，确认仍可预览所选原件；开始分析后，应使用当前方式重新得到结果。

**通过标准：** 添加后立即可浏览原页总览；来源、页码和缩略图对应正确；两种处理方式顺序、名称和选中状态正确；没有多余标题或重复入口。

## 2. 检查处理、统一缩放与无待复核微调

1. 使用“分割为全部回单”分析三栏样本，打开“片段总览”。确认片段总览显示片段卡片，切换“原页总览”后显示页面卡片；来源与页码对应正确。原页按页面计数、片段按回单计数，三栏页不应把两者数量混为一谈。
2. 在导入阶段的原页总览和检查阶段的片段/原页总览分别使用缩略图控件，逐次点击“−”、点击“＋”，并观察百分比或尺寸值变化。确认控件位置、操作方式和步进逻辑一致，滚动中没有横向溢出、串页或页面丢失。
3. 使用较小的测试任务，处理完全部待复核项，保留自动候选和已确认片段。此时从单选片段或详情进入“调整所选边界”，确认微调入口仍可用，不因“待复核 0”隐藏。
4. 调整首栏高度，使用复制/粘贴或统一栏位高度；点击“确认并预览本轮”，核对本轮实际影响的文件、类型、版式、栏位和数量。确认预览无误后保存本轮，可选保存为版式模板。
5. 返回结果，抽查未选中的确认片段、其他栏位和另一来源，确认只更新界面显示的同银行、同凭证类型、同实际版式范围；未确认栏位不被伪造为已确认，其他版式不被覆盖。
6. 在待复核筛选为空时，确认界面不会静默改为“全部”；如需继续微调已确认片段，应有明确的切换到全部/继续调整入口。

**通过标准：** 两个阶段的缩放操作一致；待复核为零仍可微调和保存模板；确认状态、模板边界和实际影响范围清晰且互不污染。

## 3. 模板补做与状态隔离

1. 在第 2 项保存的模板中记录模板名称、银行、凭证类型、实际版式、栏位确认数和停用状态。关闭应用后重新启动，确认“我的模板”仍可查看、选择和使用。
2. 用同银行、同凭证类型、同实际版式的新 PDF 手动选择该模板，开始分析。确认只复用已保存边界，不继承旧任务的关键词、审核结论或排除状态。
3. 用不同银行、不同凭证类型或明显不同实际版式的样本尝试自动匹配/手动选择该模板。确认不误套用；若应用提示不兼容，应保留可分析和另建模板的路径。
4. 如果此前存在尚未确认的栏位，另建或更新模板时只确认实际已核对的栏位。重新分析同版式文件，未确认栏位必须仍显示待处理，不得因模板名称或旧任务状态被自动标为已确认。
5. 停用模板族，再分析同版式文件；确认不回落到旧模板、旧来源校准或旧审核状态。重新显式保存的新模板应可用，停用的模板不可被自动匹配或手动选用。

**通过标准：** 模板可跨任务复用边界但不复用旧审核状态；名称、当前模板、确认栏位和停用状态同步；跨类型、跨版式、停用后的隔离正确。

## 4. 直接导出、三种方式与取消/重试

前置条件：使用一个已处理完的任务，确保所有待复核项已确认或排除；保留一个较小的任务和一个多来源任务各测一次。导出范围应包含全部未排除片段，不随当前总览筛选或当前勾选缩小。

1. 进入“导出文件”阶段，确认页面直接显示导出名称、导出方式、XLSX 选项、清单 JSON 选项和“选择目录并导出”。不应再要求先点击“生成预览”或进入第二个导出预览页面。
2. 分别选择三种导出方式并成功导出：合并为一个 PDF、按来源分别导出 PDF、同时导出两种 PDF。每次使用独立输出目录，核对 PDF 数量、页数、来源顺序、首尾内容和排除项均符合本轮范围。
3. 点击“选择目录并导出”后，在系统目录选择器中点击取消。确认没有生成文件，页面仍保留导出设置和可再次导出的入口。
4. 若导出中自然遇到可恢复的写入失败，记录提示；原因解除后点击“重试导出”，确认仍使用同一次导出和已选目录，成功后只保留一套完整输出。没有遇到失败时此项记为未触发即可，不必修改系统权限或故意破坏输出目录；中断与重试另有自动化覆盖。
5. 导出成功后确认页面显示实际输出目录和生成结果；如使用“移除本次来源”，只能影响当前任务，磁盘原件仍可打开、页数正确且哈希不变。

**通过标准：** 三种方式均能直接导出；取消不产生半成品；失败可重试且不会改变导出意图；导出范围、PDF 内容和原件保护正确。

## 5. XLSX、清单 JSON、智能命名与原件保护

1. 新建任务完成一次全部分割导出，先保持“同时导出 XLSX 索引”和“同时导出清单 JSON”均未勾选。确认输出目录包含 PDF（或所选 PDF 组合）且不包含面向用户的清单 JSON；若关闭 XLSX，也不应出现 XLSX。
2. 只勾选 XLSX，再导出一次，确认 XLSX 索引数据行数、来源页码/栏位和 PDF 页数一致，排除项不在索引中。
3. 只勾选清单 JSON，再导出一次，确认输出目录出现清单 JSON，内容对应本次任务的实际范围、处理方式、来源和输出文件；默认关闭时不能残留上一次任务的 JSON 选项或输出。
4. 分别测试单来源全部分割、单来源关键词查找和多来源导出。确认默认名称能体现原件/银行和处理方式，例如“原件名 + 全部回单”“原件名 + 关键词 + 查找结果”或“多来源 + 文件数”；名称可以编辑，非法路径字符和 Windows 保留设备名被阻止。
5. 核对导出目录使用可辨认的名称前缀并附带时间/防重名后缀；再次导出不会覆盖先前结果。检查输出 PDF 文件名与导出名称一致或能明确对应。
6. 重新计算所有输入副本的文件数量、字节数和 SHA-256，和开始前逐项比较；检查原目录文件名和修改时间。导出、模板、排除、恢复、移除来源和导出失败重试均不能修改原件。

**通过标准：** JSON 默认关闭、显式开启有效；XLSX 按选项生成；名称和目录自动可辨认且可编辑；输出无覆盖；原件数量、字节数、SHA-256 和文件名保持一致。
