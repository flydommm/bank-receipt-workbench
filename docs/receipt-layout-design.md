# 回单版式设置与批量提取：完整方案

状态：已进入目标模式实施；各阶段实际进度见 TODO，尚未交付完整新功能。日期：2026-09-14。

配套：[实施 TODO](receipt-layout-todo.md) · [验收矩阵](receipt-layout-acceptance.md) · [当前微调流程](guided-review-workflow.md)。

本方案整理已讨论的产品方向，包含为落地补齐的具体规则。准备文档在提交 `0c6b9fe` 完成，随后用户开启目标模式进入实施。现有安装包和当前功能行为以使用指南为准；不能将计划项视为已交付能力。

## 1. 目标与范围

财务人员导入多个 PDF 后，可以直接分割全部回单，也可以按关键词提取命中的回单。分割框来自稳定版式；关键词只决定选哪些回单。自动结果正确时直接导出；只有边界不合适时，才校准一套版式并应用到同版式、同位置的目标。

### 本次拟实施范围

- 自动读取真实页面尺寸和方向，建议每页栏数、统一高度及各栏距页顶位置。
- 支持纵向排列的规则回单；“栏”指上中下排列的回单位置，不指文字分栏。1/2/3 栏为常用快捷项，其他纵向栏数可自定义，不将模型硬编码成三栏。横向并排和不规则网格保留现有独立裁剪路径，提示不适用本模板编辑器，不猜测套用。
- 统一高度可解除；整页同时显示所有栏位。左右边距默认零，支持展开调整。
- 显式选择“按关键词提取”或“分割全部回单”，二者共用版式几何。
- 同出具银行、同实际版式、同位置跨 PDF 应用；原生单张继续整页，多栏单张尾页继续用相应栏位。
- 简化调整、整批预览、保存、撤销和继续其他位置流程。
- 人工确认的常用版式保存在本机，下次匹配后用作候选参考。
- 同步更新帮助、协议、持久任务、导出、测试和本地安装验收材料。

### 不在本次范围

云端模板共享、自动发送业务材料、根据银行名称建立全国统一裁剪参数、直接控制打印机、对原件做原地裁剪、为不同纸张自动缩放套模板、任意网格模板编辑器。导出仍沿用现有合并、按来源和可选审核索引能力。

## 2. 当前证据与设计取舍

| 当前情况 | 已核对的边界 | 本方案处理 |
| --- | --- | --- |
| 手工框稍微扩大就报保护边界错误 | `src/domain/batchCrop.ts` 同时将样本和目标的自动 `receipt.bounds` 作为硬边界；错误毫米数不是三栏高度之和 | 新增显式版式校准路径，允许修正自动边界；纸张和人工定义的相邻栏位仍硬校验 |
| 同一银行仍可能只有一个片段进入本轮 | 当前分组还依赖出具银行、实际模板、位置及人工保护状态 | 显示完整应用清单与排除原因，不用自动确认状态缩小同类范围 |
| 微调同步已有基础 | 规划器已按标题锚点平移样本最终框 | 常规自动裁剪继续使用原路径；新模板使用明确槽位几何，不叠加两套变换 |
| 不同月份复用 | 现有审核恢复绑定源文件身份和搜索条件，不是跨文件模板库 | 常用版式单独存储；不把旧审核记录自动升级为历史模板 |
| 大轮次曾触发 React 更新深度错误 | 现有修复覆盖文件列表与频繁缓存更新 | 保留超过 50 个页面、生产 React 和真实组件组合的回归 |

选择“整页版式定义”而非逐银行写固定参数：银行只负责来源隔离，同一银行可有多个真实版式，同一版式也允许付款、收款等经核实的内容变体。自动识别不足时明确降级，不拿文件名或交易对手开户行替代出具银行。

## 3. 核心对象与适用范围

以下名称为拟新增概念，具体类型由 TODO 中的协议步骤一次落实：

| 对象 | 含义 |
| --- | --- |
| 工作范围 `workspace_id` | 本地模板分组，首次使用提供默认工作范围；需要区分公司时由用户创建或选择，程序不从文件名、交易正文推断公司 |
| 页面几何 `page_geometry` | 有效可见页框、原点、旋转、PDF 单位与显示坐标映射；不是截图像素尺寸 |
| 版式定义 `layout_definition` | 几何、版式证据、栏数、各栏位置和宽高、统一高度开关、版本、人工确认来源 |
| 回单槽位 `slot` | 整页中的第 1/2/3 栏，独立于该页命中序号；尾页只剩第 1 栏仍叫第 1 栏 |
| 回单实例 `receipt_instance` | 某来源文件、某页、某槽位内的实际回单；同张多个命中只对应一个实例 |
| 批量预览快照 `preview_snapshot` | 本次确切目标、框、来源及审核版本、模式、条件、异常处理决定的不可变集合 |
| 常用版式 `saved_layout` | 用户明确要求记住的版式版本，不包含上次交易数据、关键词或新文件的审核结论 |

批量应用范围为“当前任务选入文件 ∩ 当前工作范围 ∩ 已核实出具银行 ∩ 已验证版式 ∩ 本轮受影响位置”。列表筛选只用于查看，不能偷偷缩小保存范围。自动确认且未人工修改的同类实例全部纳入；人工独立修改、明确保留整页等例外单列，默认保留，用户可明确纳入覆盖后重新预览。

未知银行或版式无法验证时，允许在当前 PDF 的人工指定范围校准并预览，禁止自动跨 PDF 同步或跨文件历史套用。界面明确显示“仅当前 PDF，来源/版式尚未核实”。人工选定范围也必须经过页面几何与逐页异常检查。

## 4. 页面尺寸、建议框与统一高度

### 坐标与单位

- UI 默认毫米，数值显示到 0.1 毫米；内部保留 PDF 坐标精度，不用显示舍入值反复计算。
- 编辑坐标以旋转后的有效可见页面左上角为原点；后台负责与原 PDF 坐标可逆转换，包含非零 CropBox 原点及 PDF UserUnit。
- 缩放预览不改变实际尺寸；旋转后的宽高、命中框、拖动坐标和最终导出使用同一转换。
- 页面框无效、旋转或单位无法支持时进入异常状态，不能按 A4 猜测。

### 建议算法

1. 读取实际页高、页宽和方向，读取与搜索条件无关的文本、图像标题、分隔线、留白等版式证据。
2. 优先使用本工作范围内唯一且兼容的已保存版式；其次使用当前文件经验证的版式证据；最后提供人工栏数和等高初始框。
3. 栏数建议来自完整版式证据，不能用关键词命中数、该页实际剩余回单数决定。需要参考完整页时采用有预算的按需检查，不能每进入一个位置就重复扫描全文件。
4. 若顶部留白为 `a`、底部留白为 `b`、栏间距为 `g_i`，则初始统一高度为 `(H - a - b - Σg_i) / n`。证据不足先用 `H/n` 作为初始建议，显著标明需要检查；等分不是识别成功。
5. 根据可验证的标题、分隔线及留白校正各栏起点，保证完整回单内容有空间；不存在安全的共同高度时，提示解除统一高度或调整位置，不能自动裁掉内容来满足等高。
6. 多栏尾页沿用原版式的槽位位置，不按尾页实际数量重新均分，不把空白占位变成回单。

### 用户设置与约束

主要控件：栏数（1/2/3 快捷项及自定义）、统一高度开关及高度、当前栏位距页顶位置。栏数须为正整数，且不能超过页高与引擎最小合法裁剪高度允许的数量；在分配槽位前校验，不能接受无限大输入。首栏顶部默认 0；拖动框与数值双向联动。左右边距及单栏独立高度放在高级设置。首次打开填入建议值，不要求用户先测量。

统一高度开启时，调整某栏顶部只移动该栏；调整上下边界会改变共同高度，实时显示对各栏的影响。关闭时只改变当前栏。左右边距作为整套版式共享参数，不提供隐含的单栏宽度变化。

设第 i 栏顶部为 `t_i`、高度为 `h_i`，所有框须满足：

- `0 ≤ t_1`，所有高度为正，左右边距之和小于页宽；
- `t_i + h_i ≤ t_(i+1)`；
- `t_n + h_n ≤ H`。

边界允许相接，不允许有正面积重叠；数值计算仅允许机器精度误差，不能用毫米级容差掩盖真实重叠。总高度不超过页高是必要条件，不代替以上逐栏约束。检查包括未命中的相邻槽位。

导出保持原内容比例。统一裁剪尺寸与打印机缩放是两件事；本次不靠拉伸内容或改变打印机设置来制造尺寸一致。

## 5. 两种处理模式与关键词不变性

导入后明确单选“按关键词提取”（默认）或“分割全部回单”。空关键词仍是关键词模式的输入错误，不能隐式切换全部导出；切换模式保留输入草稿，但重新分析并使旧预览失效。

共同流程：源文件核实 → 页面及版式分析 → 槽位与实际回单实例 → 模式筛选 → 候选与审核 → 最终导出预览。

### 按关键词提取

- 在回单实例内执行现有精确、模糊、包含全部/任一/排除等条件。不能把同页不同回单的文字拼起来满足 AND。
- 同一回单多个命中去重；同页不同回单分别输出。审核索引区分命中次数和输出回单数。
- 同一来源、同一版式版本的分割几何不随关键词变化；文字读取与几何缓存复用，条件筛选单独计算。
- 命中跨过建议分割线或回单归属不确定时列入异常，不静默丢弃。人工修改边界影响实例归属时，必须重算该版式范围的实例及筛选结果，再生成完整新预览；不只更新旧框而保留错误命中归属。

### 分割全部回单

- 无需关键词，输出实际存在的回单，保持来源文件顺序、页码顺序、页内自上而下顺序。
- 不输出确认空白的槽位或明确无效联；正文中提到“空白联无效”不能据此删除整张回单。
- 无法确认空白/有效的槽位保留为异常，用户预览后明确保留或排除，不能静默消失。
- 图像页可按已确认模板切框；Core 无法完成的文字识别、银行核实或有效性判断明确提示，不以空识别结果当作空白。跨文件自动套用仍需足够版式证据。
- 模式进入协议、任务、恢复和导出上下文，不能通过通配关键词或伪造命中实现。

## 6. 界面与步骤

### 常规结果页

原文件区可折叠，保持文件数量、当前文件和处理进度可见。中间以 PDF 预览为主，右侧显示结果；主操作为“选择导出范围”，次操作为“调整版式”。微调不是必经步骤，不要求所有银行、所有栏位都人工确认。

### 版式编辑页

```text
版式：当前已核实版式                    调整中 · 尚未保存
┌──────────────────────────┬──────────────────────┐
│ 原 PDF：同时显示各栏绿框   │ 每页栏数： 1  2  3   │
│ 首栏                      │ 统一高度：开 / 关     │
│ 中栏（当前，突出边框）     │ 回单高度：建议值 mm   │
│ 尾栏                      │ 距页顶：建议值 mm     │
│                           │ ▸ 高级设置           │
└──────────────────────────┴──────────────────────┘
首栏 · N 处 · 已保存 | 中栏 · N 处 · 调整中 | 尾栏 · N 处
本次影响：当前版式、所选位置、N 个 PDF、M 张回单
                           [确认并预览] [取消当前调整]
```

样例是结构草图，不是固定像素设计；数量使用实际统计。仅显示实际存在的位置按钮；“第 i 栏”是稳定身份，首/中/尾为辅助名称。超过三栏时按第 i 栏列出，可换行或横向滚动，不把多个中间栏合成一个位置。

点击位置按钮后，样本和右侧列表同步切换。保留进入前所选文件、页和槽位，不默认跳到第一条待复核。变更位置但无草稿时无需额外确认；有草稿时显示“继续调整 / 放弃未保存调整并切换”，不自动保存。已保存的其他位置保留。

统一高度或栏数/共享左右边距变化影响整套版式：自动扩展本轮至受影响各栏，列出原已保存结果中会改变的项，必须重新预览和保存，不能只改画面不更新先前结果。仅改变某栏起点时，本轮只影响该位置，但仍检查全部相邻栏位。

### 状态与按钮合同

| 状态 | 常驻提示 | 主操作 | 次操作 |
| --- | --- | --- | --- |
| 结果检查 | 候选/待复核数量、使用的版式来源 | 选择导出范围 | 调整版式 |
| 准备中 | 准备阶段、已处理/总量、当前样本 | 无保存按钮 | 取消准备 |
| 调整中 | 当前调整尚未保存；无改动时说明可直接预览 | 确认并预览 | 取消当前调整、返回结果 |
| 预览生成中 | 实际进度，尚未保存 | 无保存按钮 | 取消预览 |
| 预览就绪 | 本轮 M 张，尚未保存；异常/排除数量 | 保存本轮 M 张 | 返回调整 |
| 保存中/结果未明 | 正在保存或等待核实，避免重复写入 | 查询/重试同一操作 | 按恢复合同处理 |
| 已保存 | 本轮已保存 M 张，剩余位置数 | 继续其他位置或返回结果 | 撤销本轮 |

“确认并预览”只表达完成当前编辑并生成预览，不写入审核决定；“保存本轮”一次保存并确认，不再要求第二次确认。保存状态、影响范围、异常、撤销入口不能折叠。详情和帮助可以展开；每阶段最多突出一个主操作。

不再强制执行“检查本银行完成情况 → 完成本银行 → 完成全部银行”的重复按钮链。银行用于组织导航；当前范围完成后即可返回结果，正常导出仍检查所选范围的有效审核状态。

### 预览与可访问性

- 右侧显示本轮完整影响清单，可逐张预览；显示位置、源页、是否变更、人工例外与排除原因。预览清单不能只显示样本或只显示待复核。
- 用户可抽查后保存整批，不强制点击每张；不得把“生成预览”标成“每张人工看过”。异常项必须明确处理。
- 多选仅用于明确排除或纳入例外，默认范围自动建立。下拉框用于较多文件/历史版式选择；首中尾位置直接显示，不藏在下拉框。
- 所有输入有标签、键盘焦点和错误关联；数字输入支持键盘操作，位置按钮支持键盘切换。颜色以外同时提供状态文字。
- 局部沿用现有字号层级：当前主要按钮约 12px、版块标题 16–18px；新编辑核心文字建议 12–14px，说明不小于现有正文。不能单独扩大标题挤压预览，也不照搬辅助 10px 字号承载关键错误。
- 在 1366×768、1920×1080、Windows 100%/125%/150% 缩放验证；主按钮和保存状态可达，不用全页滚动寻找保存。页数少时列表按内容高度排列，避免一条结果撑满整个栏。

## 7. 校验、批量保存与恢复

### 两条校验路径

1. **现有自动/独立裁剪路径**继续保留原保护规则，不全局删除 `receipt.bounds` 检查。
2. **显式版式校准路径**以整页几何和用户定义的完整槽位关系检查；自动 `receipt.bounds` 是参考，不再单独阻止校准。后台重新计算并核验，前端无法通过构造请求绕过。

纸张外、无效数值/坐标、槽位正面积重叠、来源变化、错误银行/版式、过期快照属于硬错误。自动边界偏差、可能裁到标题/正文/印章/二维码属于可视化内容风险，显示涉及位置与范围，由用户调整或明确确认；不能静默收缩、钳制、缩放或宣称绝对完整。命中归属不确定先重新计算并明确处理，不能以风险确认替代实例归属。

### 快照与提交

- 预览快照绑定 task/context、处理模式、条件指纹、源文件身份、页面几何、版式版本/哈希、目标实例与坐标、审核修订、例外选择及风险确认。
- 任意编辑、来源增加/移除/变化、切换模式或关键词、采用其他版式、冲突处理变化均使预览失效，保存按钮不可继续提交旧集合。
- 保存由后端按快照重验，原子写入本轮目标、确认和操作记录；全部成功才显示已保存，失败不部分确认。需要跳过的项目必须在提交前反映在预览中。

持久化实现以任务 SQLite 为本轮的权威记录：页面检查点、新结果快照、完整审核决定与操作 ID 在同一事务中提交。既有独立审核库是该结果的投影，用另一个事务整体替换；两个数据库不宣称具备跨库原子事务。两步之间中断时保留 `committed` 待恢复状态，界面先按操作 ID 查询或重试同步，只有投影整体完成才显示 `applied`/本轮已保存。新结果与旧审核投影的修订不一致时，读取和导出不得混用；重启准备审核会恢复该操作。预览和操作明细保存在任务私有库，并随任务清理，不进入可复用版式库。
- 重试使用同一 operation id，确认写入结果不重复执行。写入结果未明时先查询同一操作；不能以取消草稿假定没写入。
- 当前任务重启恢复已保存结果；内存草稿不冒充持久保存。退出/取消准备使旧异步回调失效，不能重入后又跳回旧位置。
- 撤销按已保存操作恢复本轮全部目标，核对目标修订，保留其他轮；若后续轮已修改同一目标，按逆序撤销或显示冲突，不能覆盖较新结果。保存失败后的历史模板写入不能改变当前轮是否已保存的事实。
- 若本轮记住过历史版式，撤销必须先按第 8 节暂停仍依赖本轮确认的历史参考，再撤销审核；两步使用同一撤销操作 ID，未完成时不能显示整轮已撤销。

## 8. 常用版式与历史参考

首次提供“记住此版式供下次使用”选项，默认不勾选；用户可以保存本轮而不保存历史模板。已启用的工作范围保留用户偏好，但每次明确显示是否记住。只有人工保存确认过的定义可进入模板库，自动候选不能悄悄成为人工模板。

### 保存与匹配

- 保存本地工作范围 ID、版式 ID/版本、已核实出具银行、实际版式证据和算法版本、页面几何、各栏定义、人工确认时间与来源操作 ID；用户命名仅本地使用。
- 按槽位及共享参数记录确认来源与 `confirmed_slot_ids`。只有本轮实际预览并保存的位置可用于历史自动参考；只保存首栏不能把中/尾栏一起晋升为人工确认。未确认位置可以保存为建议，匹配时仍走自动分析或待检查。后续轮补齐生成新版本；共享高度等参数改变后，受影响位置的旧确认失效，需重新预览保存。
- 不保存 PDF 内容、OCR 正文、账号、交易对象、关键词或原件绝对路径到可复用模板。审核任务仍保留其原有本地追溯记录。
- 识别依据不能只用银行名、文件名或纸张大小；使用已有稳定模板证据，并为“页面版式家族”核实允许的回单变体。身份不包含关键词、人工框坐标、交易内容、槽位序号或尾页实际数量，避免改框后无法匹配自己、尾页变成另一版式。
- 第一版采用保守匹配：同工作范围、同出具银行、兼容的稳定版式证据、相同方向；有效页宽高差不超过 0.5 PDF point（仅吸收表示误差）。不按比例缩放套用；新尺寸或证据变化另建/重新校准。
- 唯一匹配时提示“参考已保存版式”，仍逐页验证纸张、内容分布及有效槽位。多模板冲突让用户选择，不凭最近更新时间任取一份。未知来源、证据不足不能静默自动套用。
- 页内轻微漂移仅在能验证完整布局、且整页一致平移仍合法时生成带提示的建议；不能把一处文字锚点变化当成全部版式漂移，也不能改变历史原定义。

### 与审核数据分离

历史模板生成新候选，不继承旧文件人工确认。新候选按新任务的计算质量/导出规则检查；参考模板无需强制进入微调，但模板曾确认不等于新任务所有实例已人工审核。

沿用应用私有数据目录，使用独立版本化模板存储，不把现有基于 source SHA/search context 的恢复记录直接用作模板库。当前轮保存与模板记忆采用明确的两步持久化：审核决定先原子成功；再幂等保存模板。后一步失败显示“本轮已保存，常用版式未记住”，提供重试，不重复保存整轮或误报整个操作失败。

模板更新生成新版本，已存在任务绑定原版本快照；停用模板影响未来匹配，不改变已保存任务。删除/清理模板前明确影响，保留已有审核记录；首次实现提供停用和新版本替换，不加入自动清理。旧版应用无法读取新模板时不能改写或清空它。

### 撤销与历史参考联动

每个模板槽位/共享参数保留其确认操作 ID。撤销本轮时，所有仍引用该确认的模板版本保守地整体暂停自动参考；已经独立重新确认、且不再引用该操作的新版本不受影响。已有任务快照及其他轮审核不改写，不自动启用另一个旧模板版本。

跨存储撤销先在模板库幂等登记“确认来源已撤回”标记并暂停相关版本，再撤销审核。后续/延迟模板写入必须在同一模板事务中检查撤回标记，不能在撤销后重新激活旧框。第一步失败不执行审核撤销；第二步失败显示“历史参考已暂停，本轮撤销尚未完成”，按同一撤销操作 ID 查询或重试。未记住版式的轮次仍需防止先前尚未完成的记忆请求迟到，不能仅按当前模板条数判定无关联。

## 9. 架构与实施边界

### 9.1 必须先落定的数据契约

当前持久页结果 `schema=1` 要求没有 matches 时 analysis 为空，结果装配及审核 evidence 也以搜索命中为前提；因此本次是候选模型升级，不是只增加控件。

- 显式处理模式 `processing_mode = search | split_all`。关键词模式继续严格校验非空条件；全部分割模式不制造隐藏关键词、匹配任意字符串或伪造命中。
- 候选选择依据 `selection_basis = keyword | occupied_slot | manual_slot`；关键词模式保存真实命中 evidence，全部分割允许没有搜索 evidence，但必须有有效槽位/人工选择依据。不能把裁剪框冒充 `match_rect`。
- 引入独立于筛选的 `slot_id/position_index` 和实例 ID：来源内容身份、页、版式应用修订、槽位共同确定实例；`segment_no` 仅用于展示，不作为模板或实例的永久身份。当前 5% 标题位置桶只能作建议证据，不能作为新槽位主键。
- 分别升级任务请求白名单、分页检查点 schema、结果快照 schema、TS/Python 装配契约及审核分析清单。新字段进入稳定签名；模式、人工模板修订、实例依据或来源变化后不能恢复旧结果。
- 区分页面描述 fingerprint、单张 `receipts[].template_fingerprint` 与审核 `layout_fingerprint = geometry:...`。历史匹配使用真实版式证据；坐标字符串不能作为跨月身份。
- `engine/computation.py` 的计算源文件清单必须包含新增几何/选择器模块；计算版本、任务结果版本和历史模板版本分别管理。
- 任务清理不删除独立常用版式；模板停用不修改任务中已经绑定的版式快照。

### 9.2 分层职责

- **前端领域层**：纯函数负责毫米/PDF 坐标、槽位编辑、影响范围、草稿和快照失效；组件负责交互，不在渲染过程中写审核或模板。
- **前端服务与桥接**：处理模式、版式提议、检查进度、预览令牌、批量提交/恢复、历史模板状态；取消有会话代号，过期返回丢弃。
- **Tauri 宿主**：白名单式命令与资源路径边界，传递协议和运行时能力；禁止前端任意指定模板数据库路径或原件写入目标。
- **Python 引擎**：页面几何/版式识别、有效实例和关键词过滤、校准校验、后端权威预览/原子保存、模板匹配和持久化、导出验证。
- **存储与版本**：模式和版式快照进入任务身份、恢复及导出校验；新计算规则递增 computation version。旧任务缺失 mode 时只解释为原关键词模式，不解释为全部分割。

公开协议按能力协商引入新模式/模板操作；旧宿主或旧引擎不支持时明确提示升级，禁止把新请求降级成旧行为后继续保存。新增任务/审核字段使用兼容迁移，保留旧记录；旧结果需重新分析时由用户明确启动，不能后台覆盖人工决定。

为了避免长期双实现，普通搜索和全部分割最终都由同一回单实例生成链提供几何；现有单张手动裁剪保留为例外工具。新路径验收前不替换原默认入口，不能对未完成步骤生成测试包。

## 10. 性能、验证与交付

缓存按来源内容身份、页面几何、解析/识别版本和版式证据划分；关键词缓存单独按条件划分。命中列表、文字读取、页面版式描述与预览位图不可混成一个随每次拖动全部失效的缓存。拖动只更新当前几何；点击预览才批量校验，优先复用已核实页面证据，按需渲染用户浏览页。

不承诺未经测量的秒数。必须记录冷/热文字分析、版式准备、预览、保存、导出各阶段耗时及实际重复检查页数；同轮返回调整、同版式不同关键词、只有少量待复核的场景分别比较。性能提升不能以漏查来源或异常页换取。公开报告仅保存聚合计数与时间，不含业务文字。

详细验收和命令见[验收矩阵](receipt-layout-acceptance.md)。先用公开合成数据验证跨层契约，再在独立私有工作副本上验证已有银行样本；记录原件大小/SHA-256并在处理后核对不变。真实 PDF、截图、识别正文和日志不提交。

实施完成的必要证据包括：原生整页与多栏尾页、不同关键词相同几何、全部分割、同位置跨 PDF、三位置大轮次、校准边界、历史新文件匹配、异常/失败恢复、真实 Windows 生产界面、导出裁剪与少量试打印。仅文档完成或单元测试通过不代表这些已完成。
