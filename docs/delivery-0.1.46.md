## 本轮修复

- 校准保存只为本轮实际影响的片段写入新的人工审核决定。未选且没有人工审核记录的自动候选不会被补写为人工“已确认”。
- 未改栏位的候选边界、占用情况和关键词证据一致时，继续保留原自动审核标记；如果页面重算产生真实内容越界、视觉越界或其他风险，风险仍保持待复核。
- 已有人工特殊单证分类、普通确认、排除和恢复决定按片段身份迁移，不因相邻栏位的单栏微调而串改。
- 成功保存选中的 1 处后，该处按用户的明确核对结果进入“已确认”；这不扩大同页或其他页面的确认范围。
- 版式模板的确认栏位只来自本轮实际保存且确认的栏位。完整页面结构可以继续用于同版式匹配，但不能据此把未确认栏位标为已确认。
- 关闭应用后只有在原任务确实恢复时，才能用于验证原审核状态恢复；重新分析新任务不作为原任务恢复证据。

相关原因、规则和真实样本工作副本验证见[0.1.45 微调保存审核范围验证记录](verification-0.1.45-calibration-scope.md)。该记录中的真实样本验证不替代安装包内的人工操作。

## 0.1.46 定向人工复检

入口为[0.1.46 定向人工复检单](manual-test-0.1.46.md)，本轮不要求重跑已经通过的 M01–M35。远端复检记录截至 24 条观察，结果如下：

1. 覆盖安装后帮助与反馈显示 `v0.1.46`；SH-A 初始分析为 73 处、待复核 5、排除 0，混排分类与导出门控符合观察结果。
2. 单栏微调、单处保存隔离、撤销、80mm 风险预览和待复核门控均已实际核对；重启后新任务重新分析为 73 处、待复核 5、排除 0，未继承上一任务的人工分类、排除或确认。
3. P10S1、P18S1、P26S1、P26S2 的边界已实际核对，P17S3 明确排除；四处确认后为 73 处、待复核 0、排除 1，导出入口出现。该特殊单证结论限于本轮样本。
4. 实际导出得到 PDF、JSON、XLSX 三个文件；PDF 为 72 页，JSON 选出 72、排除 1，XLSX 明细与映射各 72 行并与 JSON 映射一致。输入副本导出前后清单为 `unchanged=true`，结束目录中的两份副本字节数和 SHA-256 一致。
5. 模板保存仍为失败：0463 新模板出现保存成功提示，但刷新管理列表后未出现；旧模板的既有核对不能替代本次保存成功。该缺陷及模板重启复用、不同版式错配和停用隔离缺口保留待后续修复/复检，不能回写为 0.1.46 通过。

本节只把远端实际证据写入对应结论，不把工程回归、非 GUI 全量字段隔离或后续修复结果改写为远端人工通过。截图、导出文件和只读交叉核验记录保存在受控验收目录中。
