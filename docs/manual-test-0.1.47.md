# 银行回单工作台 0.1.47 定向补检单

本轮补检只覆盖 0.1.46 远端复检发现的“模板保存成功但列表不可见”问题。0.1.46 的单栏保存隔离、撤销、真实风险、特殊单证审核、排除和导出结果保留为对应版本证据，不要求重新执行历史 M01–M35。

## 安装与样本

- 覆盖安装 0.1.47 Core，保留用户数据；在帮助与反馈确认界面与引擎版本一致。
- SH-A：上海银行 26 页工作副本，用于验证无法可靠识别模板身份时的行为。
- HX-B：华夏银行 111 页工作副本，用于验证已知版式的单栏模板。
- 测试前后记录文件字节数和 SHA-256；仅操作工作副本，输出到独立目录。

## A. 身份不明确的版式

1. 新建任务分析 SH-A，选择普通回单第 1 栏微调，取消统一三栏高度，仅改变第 1 栏高度。
2. 进入本轮预览，确认只影响普通版式中的第 1 栏；第二、三栏以及特殊单证不在保存范围。
3. 确认“保存为版式模板”不可选，并明确说明银行或实际版式无法可靠识别；本轮边界仍可正常保存。
4. 保存本轮后，检查第二、三栏和特殊单证审核状态不被一并确认；不得显示模板保存成功，也不得新增不可见模板。

预期：普通校准和跨文件模板分开处理；身份不足不出现假成功，不能通过模板自动套用到其他银行。

## B. 已知版式的部分确认模板

1. 新建任务分析 HX-B，仅修改一个栏位，取消统一高度；核对本轮实际影响范围后保存为新命名模板。
2. 在“我的模板”刷新，确认新模板可见、名称一致，且只标记实际确认的栏位。
3. 重新打开应用，模板仍存在；使用工作副本重新分析，选用该模板，不继承上一任务的关键词、排除或人工特殊分类。
4. 停用本轮新建测试模板，再次分析时不得继续自动应用；既有用户模板不修改、不删除。

预期：有效模板仍可保存和使用；未确认栏位不被扩大为已确认。
