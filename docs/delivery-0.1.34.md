## 本轮重点

M05 修复私有 Python 运行时缺少 `MSVCP140.dll`、在开发机被系统目录同名 DLL 掩盖的问题。发行包新增固定版本的应用私有 CRT，并在构建时检查导入依赖和实际加载位置；同时将原生文件选择器与引擎健康状态分开，健康检查失败时保留明确错误和重试入口，不回退到浏览器文件输入框。恢复后预览当前来源，不等待可选 OCR 检查。

## M05 简短复测

1. 关闭旧版应用，在干净 Windows 10 Pro x64 机器上按默认目录安装 0.1.34。启动后应显示“本地引擎已连接”；Core 包显示“OCR 不可用”属于正常情况。
2. 点击“选择 PDF”导入一份文字型回单 PDF。无需点击“开始分析”，中间应显示原件第一页，左侧显示页数。点击文件名、翻页、缩放应可正常操作。
3. 添加第二份 PDF 并切换文件，确认预览跟随所选文件；随后输入关键词并开始分析，确认能得到结果并预览命中位置。
4. 若仍提示本地引擎不可用，点击一次“重试本地引擎”，反馈提示文字或截图。无需自行安装 Python 或复制 DLL。
