# 使用指南

对应 0.1.60 Core x64，处理带文字层的 PDF。分析、审核、提取和导出都在本机进行，原件只读。

## 1. 导入与本方资料

选择 PDF 或文件夹，需要追加时使用“添加”。默认“分割全部回单”，原页总览用于确认内容和页数；按关键词筛选时选择“查找提取回单”。

启用“按交易对手整理”后默认进入“选择本机档案”，依次选择公司、来源银行和完整本方账号。没有档案时，可仅填写本批资料，或下载 Excel 模板批量建档。

导入 Excel 会完整预览公司、银行、开户行和账号，可筛选有效、重复和错误行；筛选不改变导入范围，只新增有效档案，不覆盖已有档案。账号保留前导零，勿使用尾号、遮挡值或科学计数法。重复行跳过，错误行不导入，修正后可重新导入。

每批使用一个本方账户，可含该账户多个月的多个 PDF。来源银行指回单出具银行，对方可在其他银行开户。清除或更换来源会清空上一批账户，默认回到“选择本机档案”，需要重新选择。

点击“开始回单分析”，等待分析及结果载入。资料有误时使用“更正本批资料并重新分析”。

## 2. 检查分割

在“检查与处理”切换片段总览或原页总览，按来源、凭证类型和状态筛选。

1. 检查疑似无效片段，需要时明确排除；误排除可恢复，不删除原件。
2. 核对特殊凭证的类型和范围，避免套用普通回单边界。
3. 检查普通回单抬头、交易内容、印章和末行。待复核或需调整项应完成处理，自动候选也建议抽查。
4. 必须复核项完成后，分组任务进入交易对手分组，其余任务进入导出。

### 微调边界

选中片段调整边框或数值。统一高度只改变高度，不改变距页顶的位置；首栏、中栏、末栏和尾页均应检查，避免带入相邻回单。

“确认并预览本轮”列出受影响片段，检查后保存。需要复用时可保存版式模板；模板仅保存已核对的边界，不复制上一批审核结论。同银行也可能有不同版式，不能只按栏数套用。

## 3. 核对交易对手

等待提取和分组结果载入。左侧筛选，中间勾选，右侧查看原件。先处理待确认项，再抽查自动分组。

“对方名称为空”表示原件确实没有名称；“对手待确认”表示识别或归属尚需核对。手续费、税款和结息按票面判断，可保持空白，也可由用户分别命名。

选一张或勾选最多 200 张，点击“修改交易对手”，输入名称或选择已有名称；原件没有名称时勾选相应选项。进入编辑后使用“保存所选 N 张”确认，取消不保存，不必选择付款方或收款方。已识别组同样允许批量修改。

同版式反复读取时，使用“更多工具”中的批量识别：框选名称位置，先试读、查看逐张结果再应用，可保存为本机规则。无法确定的仍待核对，人工修正不会被自动规则覆盖。细节见[交易对手整理](counterparty-grouping.md)。

提取完成后可提前导出核对草稿 Excel，草稿保留待确认原因，不等于正式导出已通过；不支持编辑草稿后回导改分组。

## 4. 检查并导出

分组任务支持“每组一个 PDF”和“合并为一个PDF”，两种方式均附总核对表，JSON 按需选择，记住上次导出方式。有待确认回单时，先修正或按界面明确纳入导出，不会静默漏掉。未完成提取、来源失败或分割审核未完成仍需先处理。

未启用分组时可合并、按来源分别输出或同时输出，索引按需勾选。查看筛选不改变导出范围。

选择目录后查看阶段进度和已用时间。百分比只代表当前可计数阶段，写入或校验阶段可能没有百分比；大文件仍可能耗时数分钟。完成前不要关闭程序。成功后查看文件数和页数；失败按提示重试，不要把暂存文件当作完整结果。

## 设置、恢复与反馈

设置用于本机界面、预览、目录等偏好；导出方式随上次选择保存。没有“历史任务”入口，关闭或重置前应完成处理与导出；出错时的“重新载入已保存结果”只恢复该任务已保存状态。

“帮助与反馈 → 使用反馈”可预览、复制或保存 TXT，再通过自己的邮件或微信主动发送。GitHub 公开反馈入口已移除。发送前去除客户、账号、文件名和路径，不发送真实回单或未经检查的日志。

Core 不包含 OCR。单文件默认最多 5,000 页、500 MiB，每次最多 500 个 PDF；提高配置不代表该规模已经验证。
