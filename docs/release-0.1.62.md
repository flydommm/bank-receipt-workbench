# 0.1.62 版本说明

Windows x64 Core。本版修正版式微调中统一高度切换的范围提示与恢复行为。

## 本版改动

- 统一高度模式下调整一栏后取消勾选，会明确选择“仅保留当前栏，恢复其他栏位”或“保留已同步的多栏修改，仅关闭后续联动”。
- 微调区域显示当前高度调整预计影响的页数和栏数，预览前即可识别 9 处或 27 处等范围差异。
- 同步更新 README、随附 `readme.txt` 和微调流程说明。
