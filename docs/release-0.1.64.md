# 0.1.64 版本说明

Windows x64 Core。本版修复两列付款人／收款人表格中交易对手名称漏读，以及名称、开户行换行识别不完整的问题。

## 本版改动

- 名称字段支持“全称、名称、户名”等通用标签，不依赖银行名称或固定左右位置。
- 角色逐字竖排或角色栏较宽时，按对应列唯一关联付款人、收款人的名称、账号和开户行；角色不完整或关联存在冲突时保留待确认。
- 补读名称、开户行的紧密换行，限制跨行范围，避免把摘要等相邻内容误并入字段。
- 根据票面角色和本批账号判断本方，继续区分交易对手、本公司内部往来和原件明确空白，不用本方名称或摘要填补对手空白。
- 安装修复版后，重新分析原 PDF，再进入交易对手分组。原有人工修正和本机读取规则仍按既有规则处理。

## 验证范围

- 相关回归验证：1,217 项通过。最终字段边界调整后，183 项字段相关测试通过，其中包含 21 项本次专项回归。
- 专项用例覆盖通用名称标签、宽角色栏、竖排角色、名称及开户行换行、摘要隔离和冲突处理。
- 本地 131 页样本的 786 个字段逐单元格比对一致；分组结果为 105 张有名称交易对手、25 张内部往来、1 张原件名称空白、0 张待确认。原件哈希未变。
- 上述验证不代表任意陌生版式均可免核对；名称缺失、角色冲突或边界不明确时仍需对照原件处理。
- 安装包构建、资源核验、签名状态和 Windows 安装验收以本次交付清单为准，本说明不将源码测试视为安装验收。
