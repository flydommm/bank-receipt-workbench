# 0.1.47 模板身份防护交付记录

0.1.47 修复了版式模板在出具方或实际版式身份不足时出现“保存成功但管理列表不可见”的问题。模板复用资格现在要求稳定的 `issuer_id` 和 `family_id`；身份不足时只保留当前 PDF 的本轮边界审核，模板入口不可选，后端也会在审核结果持久化前拦截模板写入。已知身份的部分栏位仍可保存为部分确认模板，跨银行和跨实际版式的复用资格继续由既有身份、版式指纹、页面几何和栏位结构约束。

本记录区分工程验证与远端人工复检。当前 0.1.47 已完成本轮定向检查：覆盖安装与版本、SH-A 身份不足场景、HX-B 部分确认模板保存/刷新/重启、停用后再分析、模板历史完整性和工作副本一致性均已核对通过。结论限定在本次身份防护补检范围内，不替代完整产品验收，也不把 SH-A 身份不足场景扩展为跨文件模板支持。

## 与 0.1.46 证据的关系

0.1.46 已有远端证据包括安装版本、单栏保存隔离、撤销、真实风险、待复核门控、特殊单证样本、排除项和 72 页导出核验。0.1.46 曾观察到新模板出现保存成功提示但未进入活动列表；0.1.47 的身份前置校验和 SH-A GUI 复检针对该缺陷补强。0.1.46 的 GUI 结果不计作 0.1.47 的 HX-B 模板通过证据。

定向操作步骤见[0.1.47 定向补检单](manual-test-0.1.47.md)。工程报告、测试明细和远端截图继续保存在受控验收目录中；本文件不写原件详细路径、金融姓名、账号或金额。

## 范围与边界

- 停用后的再分析恢复 327/0/0 自动候选，本轮新模板未继续自动套用；模板完整性清单确认既有 13 条模板和 5 条撤销记录未被修改或删除，仅新增 `047-HX-S1` v10 且已停用。
- SH-A 身份不足时仅证明当前 PDF 的普通边界可以保存；“保存为版式模板”保持禁用，跨文件模板复用仍不支持。HX-B 仅核对 1/3 栏位，不扩展为三栏全部确认。
- 本轮结论为 0.1.47 身份防护定向检查在当前范围通过；工程测试与 0.1.46 GUI 证据仍按各自版本记录，不能合并为全量产品验收结论。
