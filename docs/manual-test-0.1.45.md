# 银行回单工作台 0.1.45 定向人工复检单

目标包：`0.1.45 Core x64 NSIS`。本轮只复检人工凭证分类、特殊单证与普通回单隔离、版式模板边界、排除/恢复和导出门控。用户已经通过的 M01–M35 不需要因为版本号变化重跑；本清单的六项结果全部从 0.1.45 安装后重新记录。

工程自动化和真实样本副本验证不能代替安装后人工验收，相关范围与结果单独记入交付记录。本清单只记录本版人工结果。

## 开始前

- 安装或覆盖安装 0.1.45，打开“帮助与反馈”确认版本为 `v0.1.45`。不要把旧任务恢复当作本轮测试输入。
- 准备样本：三栏普通回单（HX-A、HX-B）、包含特殊单证的上海银行样本（SH-A），需要验证不同银行时可用民生银行样本（MS-B）。所有样本使用独立工作副本。
- 记录每份副本的文件数量、字节数和 SHA-256；在本轮结束再次核对。导出、移除来源、排除、恢复、分类和模板操作均不应改动原始 PDF。
- 每项记录来源代号、页码、栏位、当前筛选、操作前后数量和截图路径。状态只填写“通过”“失败”“阻塞”或“跳过（待补测）”。

## 1. 导入后默认“分割全部回单”

1. 新建任务，添加一份 PDF，等待读取完成。
2. 确认中间栏默认显示“原页总览”，右侧默认选中“分割全部回单”；不应默认进入“查找提取回单”。
3. 确认右侧两项文字和顺序为“分割全部回单”“查找提取回单”，不再显示多余的“处理方式”标题。
4. 先不分析，切换原页总览/单页和缩略图大小，确认原件可预览、页数正确；再使用默认方式开始分析。

**通过标准：** 新任务默认走全部分割，导入后可先看原页总览；处理方式名称、顺序、选中状态和页数一致。

## 2. 上海银行特殊单证自动提示与未知单证分类

使用 SH-A 完成一次分析，在“来源与类型”或“待复核”筛选中检查自动识别结果。

1. 确认第 10 页贷款清算通知书、第 18 页贷款利息到期通知书各为完整一张；第 26 页两张电子缴税付款凭证显示对应类型。第 17 页第 3 栏的无效片段按内容判断是否排除，不能因为待复核就直接确认。
2. 对自动识别未覆盖的特殊单证，先单选一处，打开“设置凭证类型”，选择“其他特殊单证”或实际类型；确认只改变当前片段的类型。
3. 再在同一筛选范围多选多个片段，批量设置同一类型；确认数量、类型和选中范围正确，未选片段不受影响。若样本没有未识别单证，可在独立测试任务中用普通片段验证人工改分类，随后明确改回普通；不把临时分类作为业务结论。
4. 设置类型后只保存分类时，确认片段仍为“待复核”；只有勾选“类型与边界均已核对”并确认内容完整，才同时变为已确认。
5. 发现内容不完整、误拆或属于无效片段时，不勾选完整性核对；保留待复核或进入排除流程。设置类型不能自动合并两块片段，也不能把单页通知书扩大到整页以外的内容。

**通过标准：** 自动类型提示可见；未知特殊单证支持单个/批量分类；“只设置类型”和“类型与边界均已核对”结果不同；分类不扩大选择范围、不改变普通回单。

## 3. 特殊单证与普通回单混排的单栏隔离

按“特殊单证与排除项 → 普通回单及模板”的顺序处理。没有自然混排样本时，可在独立测试任务中将三栏页的一栏临时设为“其他特殊单证”，核对保护范围后改回普通。

1. 先在片段总览筛选特殊类型，单选或多选确认自动/人工分类；需要修正边界时，进入“调整所选边界”并完成本轮预览。
2. 对含人工分类的页面，确认微调编辑器只允许当前选择的栏位修改；其他栏位、公共左右边距、统一高度和其他栏位的结构操作应锁定或明确不可用。
3. 保存本轮后返回结果，核对同页其他栏位的边界、审核状态、类型和排除状态均保持不变。再次调整另一栏时，必须重新选择该栏位。
4. 尝试保存为版式模板：人工分类页面的本轮调整不应创建可复用的普通版式模板；若是自动识别、同银行、同凭证类型、同实际版式且没有人工覆盖的特殊单证，则原有同型模板能力仍可保留。
5. 回到普通回单筛选，单选普通回单微调或应用已兼容模板；确认不会改动已确认/待复核/已排除的特殊单证。

**通过标准：** 特殊与普通混排时按栏位隔离；人工页不跨栏同步公共参数、不保存普通模板；自动同型特殊单证仍按原模板规则处理；两类操作互不误伤。

## 4. 排除、恢复与普通确认保留分类

1. 从特殊筛选中选择一处确认的特殊单证，执行“排除所选”；确认只影响任务内的导出资格，不删除原始 PDF，类型记录仍可查看。
2. 恢复该片段为待复核，确认类型仍保留，审核状态重新变为待复核，不能直接恢复为已确认。
3. 对已分类但尚未确认的特殊单证执行“确认所选”或“确认此片段”，确认普通确认不会把已有特殊类型改回普通；若要改回普通回单，必须在类型面板明确选择“普通回单”。
4. 对已排除的普通回单执行恢复和确认，确认其分类、边界和状态变化只发生在选中片段。
5. 分类或恢复后重新进入微调，确认显示当前类型、边界与范围。旧预览、旧导出范围被拒绝的并发情形已有工程回归覆盖，不要求通过多开应用或修改数据库制造该情形。

**通过标准：** 排除与分类相互独立；恢复保留类型但重新待复核；普通确认不覆盖特殊分类；分类/边界变化使旧预览和旧导出范围失效。

## 5. 普通回单微调与模板复用

1. 在普通回单筛选中选择 HX-A 的一个栏位，进入整页微调；即使待复核为零，也应能从全部结果进入微调。
2. 调整首栏高度，按需要复制/粘贴到其他栏位或统一高度，点击“确认并预览本轮”，核对实际影响的来源、银行、凭证类型、实际版式、页面和栏位数量。
3. 保存本轮并选择保存为版式模板，记录模板名称、银行、凭证类型、实际版式、已确认栏位和版本号。未选择的栏位不得伪造为已确认。
4. 清除来源、关闭应用后重新启动，添加同银行、同凭证类型、同实际版式的新 PDF，手动选择或等待自动匹配模板；确认只复用边界，不继承旧任务关键词、审核、排除或分类状态。
5. 用不同银行、凭证类型或实际版式的样本尝试使用该模板；确认不误套用，并保留重新分析或另建模板的入口。停用模板后再次分析，不应回落旧模板或旧来源校准。

**通过标准：** 普通回单始终可微调；模板只复用兼容边界；未确认栏位、旧审核状态、排除状态和停用模板均隔离；模板名称与当前选择同步。

## 6. 待复核清零后导出与原件核验

1. 回到结果总览，完成全部特殊单证、普通回单和排除项处理；确认待复核数量为 0。存在待复核时不应显示“导出回单”，清零后才显示。
2. 进入导出阶段后确认无需再次生成导出预览：选择导出方式、按需勾选 XLSX/清单 JSON，点击“选择目录并导出”即可。
3. 至少测试一次合并 PDF、按来源分别导出或两种 PDF 同时导出；确认已排除片段不进入 PDF/XLSX，确认片段和特殊单证按已审核边界输出。
4. 清单 JSON 默认不勾选；只在明确勾选时生成。输出目录和文件名应体现来源、处理方式和时间，重复导出不得覆盖已有结果。
5. 导出后再次统计所有输入副本的文件数量、字节数、文件名和 SHA-256，与开始前逐项比较；移除来源、排除/恢复、模板和导出均不能修改原件。

**通过标准：** 待复核清零后才开放导出；导出直接完成，不重复生成预览；特殊单证、普通回单和排除项范围正确；JSON 默认关闭；原件数量、字节数和 SHA-256 前后一致。
