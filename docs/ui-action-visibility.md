# 按步骤显示操作：回单工作台

日期：2026-09-20；对应源码本轮目标版本：0.1.37。

本文是 0.1.37 的界面整理和验收记录，部分按钮名及导出预览描述属于当时的历史参考。当前 0.1.57 的实际使用顺序和按钮请以[使用指南](usage.md)及[0.1.57 发布说明](release-0.1.57.md)为准。

## 本轮已确定的规则

用户明确要求：只要当前结果存在待复核项，就不显示“选择导出范围”，也不能进入生成预览或导出。不要用禁用按钮或额外说明代替隐藏。全部候选均可导出且结果非空时，才显示导出入口。自动候选未被标记为待复核时，仍无需人工保存一次确认。

这会改变 0.1.36 历史包允许导出部分可用结果的行为。0.1.37 源码实现和自动化验证已完成，安装包内的人工验收须在新的 0.1.37 NSIS 包上进行；在新包人工复测前，不提前标为通过。

当前工作区已打开导出后，如果任务、结果版本、候选集合或确认状态变化，旧预览不能继续使用。后端的完整范围校验继续保留，不因隐藏按钮而减少身份、文件、页数或审核状态校验。

本轮同时处理已定位的全部分割预览缺陷：后端默认生成“全部回单.pdf”，前端原先只接受“全部匹配结果.pdf”。支持两种合法默认名，同时保持自定义名、范围及文件一致性检查。

## 所有页面共用的组织原则

- 每个步骤最多突出一个主操作；等待期间可以没有可点击的主操作。
- 未到达的下一步不显示。短暂运行中的操作保留原位并显示处理中，防止重复提交；支持取消的步骤保留取消入口。
- 主操作放在稳定位置。返回只回到明确的上一阶段，撤销只处理已经保存的决定，取消只放弃未保存工作，三者不混用。
- 数量和状态只在一个主要位置显示。删除重复的操作说明，不用长段文字弥补不清楚的按钮排列。
- 无需调整的待复核项可以保持原框并确认。不要把“待复核”统一写成“必须微调”。
- 错误只在发生错误的步骤显示，说明可执行的恢复动作；成功和错误信息在上下文改变后失效。
- 当前模式不涉及的提示不显示。例如全部分割模式不应再要求设置关键词，也不应解释按关键词重新匹配。

## 逐阶段显示规则

下表是整体整理建议。除导出前复核门控、结果页与保存后主次调整外，其余布局归并和文案改名尚未实施，不能作为新包已具备的功能。

| 阶段 | 主操作 | 次操作与工具 | 暂不显示 |
| --- | --- | --- | --- |
| 尚无文件 | 选择 PDF | 选择文件夹 | 添加、移除、复核、导出 |
| 文件就绪 | 开始分析 | 搜索模式显示关键词；文件管理折叠 | 复核、微调、导出 |
| 正在分析或载入结果 | 单一进度状态 | 仅保留该阶段实际支持的取消/任务操作 | 重复开始、导出及无关编辑 |
| 结果有待复核 | 查看待复核 N 处 | 预览候选、必要时调整边界、返回分析 | 选择导出范围、生成预览及门控解释 |
| 已选择一组待复核项 | 已检查，确认这 N 处 | 取消确认；保持每处现有边界 | 导出；不同时突出筛选按钮 |
| 正在微调 | 确认并预览本轮 | 选栏、拖动与数值输入；复制/统一高度等辅助工具 | 保存、导出 |
| 本轮预览存在阻断问题 | 返回调整 | 取消本轮 | 导出；不突出无法执行的保存 |
| 本轮预览仍待核对 | 核对本轮列表 | 多选、全选、返回调整 | 导出；核对前不突出保存 |
| 本轮已核对且可保存 | 保存本轮 | 返回调整；记住版式作为次级选项 | 导出及无关下一步 |
| 本轮已保存 | 返回结果 | 撤销本轮、主动再次微调 | 以再次微调作为默认下一步 |
| 当前结果全部可导出 | 选择导出范围（后续建议改名“导出设置”） | 可选调整、返回分析 | 空的待复核提示、重复下一步 |
| 导出设置 | 生成预览 | 输出方式、XLSX 选项、返回结果 | 候选核对和微调操作 |
| 最终 PDF 预览 | 选择目录并导出 | 文件/页导航、缩放、返回导出设置 | 与最终 PDF 无关的旧候选导航、重复返回入口 |
| 导出成功 | 完成本次处理 | 移除本次来源、需要时再次导出 | 继续突出第一次导出操作 |

“完成本次处理”及右栏改为导出导航属于待设计实施项；当前仍沿用已有的“移除本次来源”等入口，不隐式删除任务或磁盘原件。

## 现状中优先整理的冲突

1. 结果页中心与右侧重复展示全部/待复核筛选；确认与调整同屏争夺主操作。优先保持一个主按钮，再决定筛选集中到哪一处。
2. 保存成功后继续微调原先是主按钮，容易被理解为必须再走一轮。本轮仅调主次，不删除再次调整和撤销能力。
3. 最终 PDF 预览的右栏仍是原回单候选，点选它不会改变已经生成的 PDF。后续应统一到导出文件/页导航，并归并重复返回入口。
4. “选择导出范围”实际只提供输出方式和 XLSX 选项，不提供片段勾选。后续改名“导出设置”更准确；本轮保留名称以免让用户正在执行的清单失去对应。
5. 全部分割模式仍可出现关键词相关提示；后续按当前模式清除，避免用户误以为必须输入关键词。

## 本轮验收边界

- 混合结果、全部待复核、零候选时均不显示导出入口；关键词模式和全部分割模式一致。
- 确认部分待复核项后仍隐藏；最后一项确认完成且非空后出现。
- 不增加“还有待复核所以不能导出”等门控说明，不把隐藏替换为灰色禁用。
- 旧导出工作区遇到上下文变化时撤回，等待中的旧响应不能重新展示或发布。
- 全部分割的合并版、来源版及两者同时导出均需验证；错误默认文件名、自定义名不符和错误范围仍应被拒绝。
- 复核只写入明确确认，不自动移动候选框，不修改原 PDF。
