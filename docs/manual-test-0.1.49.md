# 银行回单工作台 0.1.49 定向人工复检单

本轮只复检 0.1.49 对上海银行普通回单版式身份的修复，不重新执行已经完成的 M01-M35 全套测试。安装包用于干净 Windows 定向验收；本文件中的结果栏应在实际安装包操作后填写，不把源码回归或真实样本副本检查写成安装包 GUI 通过。

## 测试准备

- 安装或覆盖安装 0.1.49，启动后在“帮助与反馈”确认版本显示为 v0.1.49。
- 使用上海银行工作副本，以及同一实际版式的另一份 PDF 或重新创建的新任务。原始 PDF 只读；操作前后记录文件数量、字节数和 SHA-256，不在原目录改名、移动、覆盖或删除。
- 若界面提供“凭证类型”筛选，分别查看普通回单和特殊单证。上海银行第 10、18、26 页的特殊单证应单独核对，不作为普通回单模板样本。

## 定向复检步骤

### 1. 上海银行普通回单可以保存模板

1. 新建任务，添加上海银行 PDF，按当前需要开始分析；在“片段总览”按凭证类型选择普通回单。
2. 检查普通回单顶部的银行名称、回单编号、记账日期、正文和分隔位置。下一张回单顶部字段不应被并入上一张正文，也不应因斜向“上海银行”水印而把分隔位置提前。
3. 进入“调整所选边界”，只调整需要修改的栏位并完成本轮审核；选择保存为版式模板，命名为“上海普通回单 0.1.49”。

预期：普通回单能够完成版式身份核验并允许保存跨文件模板；真正跨分隔位置的正文、图形或印章仍提示需要核对。保存模板时只写入已经确认的栏位，未确认栏位保持未确认。

### 2. 同实际版式的新任务复用模板

1. 清除当前来源或新建任务，添加同一银行、同一凭证类型、同一实际版式的另一份 PDF；如暂时只有同一工作副本，可在新任务中重新添加并记录为同文件复用验证。
2. 在“我的模板”中选择“上海普通回单 0.1.49”并开始分析，或确认自动匹配后再开始分析。
3. 对比本次栏位：模板中已确认的栏位可以复用，未确认栏位保持当前分析所得的边界和状态；本次只使用当前分析条件，不继承上一任务的确认、排除或特殊单证审核状态。

预期：同实际版式的新任务能够使用该模板；模板不会因为页数、具体日期或编号变化而失效，也不会把未确认栏位伪装成已确认。

### 3. 特殊单证与普通回单隔离

1. 在上海银行结果中定位第 10、18、26 页，确认贷款通知书、贷款利息到期通知书、电子缴税付款凭证等特殊单证按实际识别结果单独显示。
2. 分别查看、微调、确认或排除特殊单证；再回到普通回单列表检查边界和审核状态。

预期：普通回单模板不改变第 10、18、26 页特殊单证的边界、类型或审核状态；特殊单证的调整也不修改普通回单模板。特殊单证可以单独处理，不要求为了验证模板而撤销既有排除决定。

### 4. 其他银行隔离与原件完整性

1. 添加华夏银行或民生银行的同栏数 PDF，检查模板自动匹配提示和“我的模板”列表。
2. 确认上海银行模板不能套用到其他银行，也不能只凭“单页三栏”套用；其他银行应按自身银行和实际版式重新核验。
3. 检查模板保存、重新分析和移除来源前后的原件数量、字节数和 SHA-256，并确认移除来源不删除磁盘原件。

预期：跨银行、不同凭证类型和不同实际版式均保持隔离；原件前后一致，导出或任务数据写入独立位置。

## 范围边界

本轮不据此推定 WebView2 缺失、不同 DPI、安装卸载、性能、M01-M35 其他项目或全部银行版式通过。若上海银行另一月份样本仍无法确认跨文件身份，应记录为身份核验失败并保留本轮边界，不通过清理特殊单证、撤销排除或手工填写银行名称绕过限制。
