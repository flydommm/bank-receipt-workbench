# 0.1.30 导出预览操作栏复测

## 测试包

- 使用同一目录中的 `银行回单工作台_0.1.30_core_x64-setup.exe`。
- 安装后打开应用，保留原件目录只读：`D:\codex\Pdf-Search\.local-data\input`。
- 本轮关注导出预览操作栏；分析结果和导出文件仍应写入新的结果目录，不覆盖原件。

## 1. 生成最终导出预览

1. 上传一个已能稳定分析的银行回单 PDF，输入关键词并点击“开始分析”。
2. 等待分析结束，进入结果检查，确认候选结果可导出。
3. 点击“选择导出范围”，保留默认的全部已确认结果，点击“确认范围并生成预览”。
4. 预览页加载完成后，检查页面底部：无需滚动整份 PDF，应直接看到“重新选择范围”和“选择目录并导出”两个按钮。
5. 切换预览文件或上一页/下一页，确认底部操作栏仍保持可见。

## 2. 加载和失败状态

1. 生成预览后立即观察预览加载过程，确认“选择目录并导出”保留在底部但处于禁用状态。
2. 模拟或等待预览页失败，确认页面显示错误和“重试预览页”，导出按钮仍存在且禁用，不会误导用户以为按钮消失。
3. 点击“重试预览页”，预览恢复后确认导出按钮自动恢复可用。

## 3. 实际导出

1. 点击“选择目录并导出”，选择新的空结果目录。
2. 确认导出成功提示、PDF 文件和可选 XLSX 索引均可打开。
3. 返回审核后重新进入导出预览，确认临时预览清理和操作栏状态正常。
