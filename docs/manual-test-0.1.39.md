## 排除与恢复规则

- “排除此片段”只作用于当前选中项；全部列表仍保留该项，供恢复或追溯。
- “恢复待复核”重新要求用户核对，不能借批量确认隐式恢复排除项。
- 没有保留项时不导出空文件；有未完成复核的保留项时不显示导出入口。
- 排除属于当前任务和分析结果；新任务或重新分析不自动继承旧排除决定。
- 若整页输出或其他保留框会重新包含已排除区域，导出应要求先返回审核处理。
- 0.1.39 为保证任务隔离升级了审核表结构；旧版会安全拒读，不能忽略新增作用域而误认已确认。回滚时须使用升级前的数据副本及 0.1.38 安装包，不能直接让旧版继续处理升级后的数据库。
