## 用户问题与边界

财务人员按交易对手、交易银行分拣并打印回单，需要同一版式的回单保持相近的裁剪尺寸。现在多回单原件中某页全部命中，或尾页只剩一张时，自动候选会扩大为整页，导致整页与单张裁剪混排。

微调联动必须以回单出具银行为硬边界，不同银行之间不得联动。付款方、收款方的开户行不能作为出具银行的替代依据；同一家银行仍需核对回单版式。

用户截图仅用于只读理解现象，不进入源码、公开文档或测试夹具。自动测试使用临时生成的合成 PDF 和虚构交易内容。

## 已确认的根因

- `engine/engine.py::_selection_payloads` 用“选中的候选数等于该页候选总数”设置 `page_fully_matched`，随后将输出区域扩大为整页。此条件无法判断原件本来是每页一张还是多张。
- `src/App.tsx` 和 `engine/batch_results.py` 的单条件组装路径直接信任该标志；多条件路径另行保留局部候选，导致两套条件行为不同。
- 原始局部 `candidate_rect` 通常仍然存在，尾页的一张回单并不一定是布局识别失败。
- 现有同类批量微调使用整页指纹，指纹包含全页标题数量、绝对位置和直线。完整三联页与单张尾页必然不同。
- 现有批量应用会将目标标为人工调整且已确认，不能直接接到每次保存上，否则第二次联动会被保护规则阻止。

## 分割规则

1. 原生每页一张回单的版式继续自动保留整页，包括正文只占页面上半部的情况。
2. 已识别出多张回单的页面始终保留各张候选框，即使全部命中，也不因命中数量合并为整页。
3. 多回单版式的单张尾页，参考同源其他页的同版式证据或明确空位/分隔证据，继续按单张框选。
4. 原件版式判断不依赖关键词是否命中；前面的多联页未命中、只有尾页命中时也应有效。版式检查需要复用解析结果并限制额外扫描、OCR 和内存成本。
5. 混合版式 PDF 按对应回单模板判断，不能把“文件内出现过多联页”套到所有页面。不能单靠候选高度占页面比例识别尾页。
6. 证据不足时保留整页、降低置信度至最多 0.89 并标为需复核。进入微调后展开“当前边界不合适”，可用“按单张候选分割”采用原始局部框，再手动检查。此操作按审核决定保存，不改变整个任务的版式分类。
7. 用户主动选择的“保留整页”继续有效。旧任务及其确认结果不在加载时自动重写；计算版本变更后，旧任务需要用原始 PDF 新建分析才能继续审核。界面明确提示新分析，不引导反复重载；旧缓存与新策略不得混用。

来源索引最多扫描 512 页原生文本，最多细查 16 个多联参考页，不额外执行 OCR。批次在已打开的 SHA 绑定工作副本内复用索引；重新恢复时重建证据。超出预算或文字、版式不可靠时保留整页，已经可靠匹配的多联模板仍可用于尾页。

## 同银行联动

- 范围是当前任务内可证明来自同一出具银行、同一回单版式的候选；可以位于同一 PDF，也可以位于不同 PDF。引导式审核把同一家银行的多个 PDF 合并为一个银行来源，但每个文件仍分别校验身份和 SHA。
- 使用出具银行标识和单张回单的稳定模板特征联合匹配。单张模板不依赖其在页面上的上／中／下位置或该页回单总数；交易名称、账号、金额等变量内容不作为匹配依据。
- 不能证明银行相同、版式不一致或版式存在歧义时，跳过并显示原因，不扩大到其他银行。现有几何检查不能可靠处理的多列布局，不强行套用纵向多联模板。
- 进入微调后自动按同一出具银行、同一回单版式和同一位置划定本轮。同一家银行的多个 PDF 合并为一个银行来源，但每个文件仍分别校验身份和 SHA；每次保存本轮时检查并同步严格匹配的候选，显示实际同步数量和跳过原因；拖动过程中不反复写入审核记录。
- 微调过程只更新当前轮草稿。连续拖动、缩放或键盘微调不会自动检查版式或保存；用户完成调整后点击“保存本轮微调”，才一次完成版式检查和样本、目标保存。保存成功会显示“已保存，N 处待确认”，用户还要点击“确认本轮 N 处”才结束本轮；没有需要调整时可点击“无需调整，确认本位置”。草稿期间不能切页、切片段或导出；版式检查失败尚未写入时，“取消当前调整”恢复开始调整前的已保存范围，不需要移除来源或重新上传文件。审核数据库写入失败或结果不明确时，只能“重试本轮保存”或“放弃失败操作并重新核对”，不能用取消或撤销猜测写入结果。
- 新框使用样本最终框相对标题的位置，映射到每个目标的标题锚点，得到一致尺寸。即使原始候选框因正文或留白差异而大小不同，也不累加上一次目标的偏移。
- 由联动带动的候选保持待审核状态，区别于独立手工调整；后续保存可以继续跟随。独立手工修改、明确确认或手动保留整页的目标退出联动并保留其结果。
- 高置信度会使原始候选自动呈现为已确认，但不等于用户确认。只有审核记录修订为 0、仍为未修改的初始候选时，才允许它参与自动联动；无法证明时继续保护。
- 样本和本次联动目标作为一次原子审核操作保存，保存失败不出现部分成功；一次撤销恢复这一批变化。
- 联动开关及成员归属先限定在本次任务打开期间。切换任务、重新分析或重启后关闭联动，已保存的裁剪结果仍保留，避免后台继续改动用户未重新检查的结果。普通导出可以依据持久化且有效的审核确认；只有重新进入微调时才建立新的引导会话，引导式审核的银行确认进度和本轮撤销记录只在当前会话内有效，重新进入后必须重新核对。退出微调不会撤销已保存的裁剪结果。
- 每个新框仍须包含命中区域，不超出纸张、不侵入相邻回单，并通过现有最小尺寸、来源变更与修订冲突检查。

## 审核操作顺序

帮助中心和审核界面按下面的顺序解释操作，避免在按钮较多时误用；完整的用户步骤见[引导式微调与审核流程](guided-review-workflow.md)：

1. 分析完成后先在“结果检查”中查看自动候选。检查绿色框是否包含回单抬头、交易内容、印章和底部末行，且没有带入相邻回单。
2. 自动边界正确时，直接点击“选择导出范围”，无需进入微调，也无需按银行逐轮确认。之后选择范围、生成最终 PDF 预览并导出。
3. 发现边界不合适时，先在结果页选中需要调整的命中片段，再点击“进入微调”。准备阶段保留当前选中的银行、版式、位置和样本，准备完成后从该位置开始，不跳到默认其他栏位；同一家银行的多个 PDF 属于同一个银行来源，当前银行剩余位置完成后再处理其他银行，不同银行不联动。
4. 进入微调后连续调整绿色候选框；拖动、缩放和方向键只保留当前轮草稿，第一次松开鼠标不会自动检查或保存。
5. 调整完成后点击“保存本轮微调”。保存完成后先查看“已保存，N 处待确认”，逐处检查后点击“确认本轮 N 处”；没有需要移动的框时使用“无需调整，确认本位置”。
6. 看到“第 N 轮已保存并确认”后，才点击“开始下一位置微调”。当前银行首栏、中间栏、末栏和单张尾页等所有位置确认后，点击“检查本银行完成情况”，再点击“完成本银行，进入下一银行”或“完成全部银行审核”。
7. 微调处于活跃状态时，普通操作和导出会暂停；完成当前微调或点击“退出微调”后才恢复。若要改选其他片段，先取消尚未保存的当前调整，再退出并重新选择。退出不会撤销已保存修改，也不代替确认，未确认或阻塞片段仍由导出范围校验拦截。
8. 已保存轮次需要回退时使用“撤销本轮”；版式检查失败时使用“当前边界不合适”或取消当前调整，不需要移除来源或重新上传文件；审核数据库写入失败或结果不明确时只使用“重试本轮保存”或“放弃失败操作并重新核对”。
9. 保存本轮后不需要另找批量应用按钮；系统已经在当前银行、版式和位置范围内尝试同步。没有符合条件的目标时显示 0 个属于正常结果，已确认或手改目标继续受保护。

## 实现与验证范围

本次同时调整了引擎候选策略和来源版式证据、前后端两套组装、页面描述与严格校验、同类匹配、联动交互、原子保存及撤销。保留现有手动批量预览功能，不放开所有已确认或人工调整记录的保护。

回归测试覆盖以下合成场景：

- 原生 A4 单张保持整页，正文只占上半部也不误裁。
- 三联全部命中仍形成三张独立裁剪；只有一张命中保持单张。
- 尾页一张加空白无效区域，裁剪与同模板完整页一致。
- 多联参考页未命中、单张尾页命中；混合原生单张与多联版式不误套。
- 相同通用标题、相似尺寸但出具银行不同，绝不联动。
- 同银行不同版式拒绝联动；同模板不同槽位及不同 PDF 正确映射。

## 人工验收

本次使用用户截图只读理解现象，未处理原始业务 PDF。以下需用脱敏原件在更新后的开发版本验收，当前已发布安装包不包含本次修改：

1. 工商式原生 A4 每页单张，仍保持整页，正文和印章完整。
2. 上海银行式多联文件的单张尾页，以及民生式三张全部命中页，逐张裁剪；核对导出预览与试打印中尺寸、抬头、末行、印章是否完整。
3. 自动候选边界正确时，在“结果检查”直接点击“选择导出范围”，确认无需按银行逐轮确认即可生成最终 PDF 导出预览。
4. 同一任务加入至少两家银行；先选中第二栏或尾栏的命中片段再进入微调，准备完成后仍从该银行、位置和样本开始，不应跳到默认位置。连续移动并缩放样本时，调整过程不应立即检查或保存，点击“保存本轮微调”后只有当前银行同版式同位置候选跟随。若有同银行多个 PDF，也检查跨 PDF 目标；另分别验证首栏、中间栏、末栏和单张尾页，再点击“确认本轮 N 处”。
5. 先单独调整或确认其中一个目标，再调整样本；该目标应保持原结果。撤销应恢复本次样本及其联动目标；显式退出微调后，未确认或阻塞片段仍应被导出范围校验拦截。版式检查失败时应可取消当前调整并改选片段，不需要移除或重新上传文件；退出不应撤销已保存修改或代替确认。
6. 银行或版式不明确时检查跳过原因，必要时使用“按单张候选分割”和手动微调。升级后的历史任务需新建分析；旧任务和已保存决定仍保留。
