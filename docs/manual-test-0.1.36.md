## 2026-09-20 追加：M07 / M25 导出预览失败

HX-A 全部分割、未微调时出现 1993 处候选 / 1342 处待复核 / 651 处旧版可导出结果；生成预览返回“导出返回内容与已确认范围不一致”。已定位为全部分割默认文件名与前端校验不一致，待后续新包复验。原 0.1.36 包不因源码修改自动成为通过。

用户已确认后续规则：只要仍有待复核项，就不显示“选择导出范围”或“生成预览”，不增加门控解释。最后一个待复核项确认后才显示导出入口；原本无待复核的自动结果无需额外人工确认。新包需按 M15、M25、M35 联合检查，详见[步骤显示规则](ui-action-visibility.md)。

## 优先复测顺序

1. **M05/M06：原件预览。** 新建任务导入 HX-A，不开始分析。记录第一次页面显示所需时间；连续切换数页并返回已看页面，再加入 MS-B 并快速切换来源。最终显示必须对应最后所选来源和页码，不被较早的响应覆盖。移除来源仍只影响任务。
2. **M07：完整分析。** HX-A、MS-B 分别新建任务，使用与上一版相同的关键词和匹配条件，从点击“开始分析”计时至结果列表可以操作。记录最终状态和候选数量；不要把进度数字走完当作实际完成。
3. **M05/M06：结果预览。** 在分析结果中切换同页不同栏，再切换不同页及来源。记录最后所选片段显示完成的时间，检查候选框和页码一致；同页换栏不应造成长时间空白。
4. **M07：统一三栏。** HX-A 普通三栏页面的距页顶使用 3.22 / 101.29 / 199.01 mm，统一栏高 96.94 mm，确认并预览本轮。记录总耗时、错误提示和草稿状态；预览应可完成，候选与风险内容可继续核对。保存、取消、导出按完整清单继续测试。
5. 速度复测后继续 M07 剩余内容及 M08 之后项目；M04 的 WebView2 缺失、Windows 125%/150% DPI 条件保持待测，具备环境时补测。既有功能结论和新包实测结果分别记录。
