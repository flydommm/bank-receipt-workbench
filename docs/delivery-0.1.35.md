## 本轮修复

- 整批版式预览：显式三栏草稿重算时跳过随后不会使用的自动候选框和版式身份重复提取；保留全部同版式页面、文本、可见对象、来源哈希和跨框风险检查。批量预览使用独立的有界时限，超时提示明确且保留草稿，其他操作时限保持。
- 页面预览：合并同页进行中请求，连续切页只保留最后一个待处理页，旧响应不能覆盖新位置；近期图像缓存保持容量限制。私有运行库随包携带经过源码哈希校验、无构建机绝对路径的 PyMuPDF 预编译缓存。
- 本轮核对：同一来源、页和栏的多条风险合并为一次勾选，底层风险 ID 全部保留；全选、Shift 连选与取消按组执行。界面区分结果变化与版式风险核对，核对不扩大导出范围。
