# 银行版式模板规则与定向复检

本文件记录 0.1.48 的银行多模板规则。工程验证与安装后的定向人工复检分别记录，复检步骤见 0.1.48 定向复检单（历史资料已归档）。

## 模板规则

- 以出具银行身份分组。同一家银行允许建立多套独立模板，由用户命名；不按公司划分，也不单凭单页栏数匹配。
- 模板适用性仍需同时满足银行身份、凭证类型、实际版式、页面几何及相应栏位。银行名称为显示标签，修改名称不会放宽匹配条件。
- 不同公司使用同一银行同一版式时可共用模板；不同裁剪尺寸或留白要求可分别保存。
- “新建一套模板”创建独立模板，从版本 1 开始；“更新已有模板”必须明确选择兼容目标，仅增加该模板的版本。
- 重命名、停用及部分栏位的边界继承仅作用于对应模板。未核对栏位不因同银行或同栏数被自动确认。
- 多套模板都适用时不自动取最新的一套、不混合其边界；检查页面提示选择模板后重新分析，也允许继续核对当前自动边界。
- 普通回单和特殊单证保持既有类型隔离。无法可靠确认银行或实际版式时，不因填写银行名称而强制生成跨文件匹配身份。
- 模板只保存已核对边界，新的关键词、命中结果与审核状态需在新任务重新计算。

## 操作顺序

1. 导入 PDF，分析后先检查特殊单证及需排除的片段。
2. 选择需微调的普通回单或同类特殊单证，调整并预览本轮，核对边界。
3. 勾选“保存为版式模板”：默认“新建一套模板”，填写名称，可填写银行名称；需替换已有尺寸时选“更新已有模板”，再明确选择目标。
4. 在“我的模板”按银行查看、选用、改名或停用。银行名称未填写的旧模板显示“未标注银行名称”，仍按其银行身份隔离。
5. 后续文件可以自动匹配，或分析前手动选用模板。出现多套适用模板提示时，进入候选列表明确选择，再重新分析。

## 定向复检（待新安装包验证）

| 检查项 | 操作 | 期望 |
| --- | --- | --- |
| 同银行多套并存 | 同一版式分别保存“常用版”和“紧凑版” | 两套都保留，各自版本 1 |
| 指定更新 | 更新常用版的一栏 | 仅常用版增加版本，紧凑版不变；未确认栏位不被额外确认 |
| 多套匹配 | 添加同银行同版式新 PDF，自动分析 | 提示多套适用，未擅自套用；选用紧凑版重分析后只使用它 |
| 独立管理 | 只改名、停用紧凑版 | 常用版名称、边界、状态不变；新任务不再使用停用模板 |
| 银行及类型隔离 | 同时添加其他银行三栏式、贷款通知或缴税凭证 | 相同栏数不导致跨银行或普通/特殊单证串用 |
| 跨公司共用 | 同银行同实际版式的不同公司 PDF | 无公司隔离要求，边界匹配仍通过银行和实际版式验证 |
| 重启与旧模板 | 重启并查看已有模板 | 旧模板及版本记录保留，同一旧系列不被拆成多套 |
| 目标已变化 | 保存前目标被更新或停用 | 不覆盖失效目标；核实未提交后可刷新、重新选择 |

本轮工程验证使用隔离临时数据库和合成 PDF，不修改业务原件或用户模板库。工程测试与安装包上的上述复检分别记录。
