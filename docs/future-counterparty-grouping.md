# 后续方向：按交易对手整理回单

记录日期：2026-09-23。来源：用户讨论确认。仅记录未来方向，不属于本轮界面改造的实施或验收范围。

用户希望在准确分割回单的基础上，按交易对手批量整理和导出同一公司、同一家银行的回单。

## 识别思路

- 先确定来源文件对应的本公司名称、开户行和本方账号；识别有歧义时允许用户确认。
- 在付款方、收款方中定位本方，优先使用账号，银行名称和公司名称作为辅助，再识别另一方。
- 此处“排除本方银行名称/账号”用于确定交易对手，不等同于现有“排除关键词”筛除整个凭证。
- 双方公司同名时，继续用账号和开户行区分，归入同名交易组，不丢弃凭证。
- 双方同银行但账号不同，不能仅凭银行名称排除另一方。
- 对遮挡账号、仅尾号、识别歧义保留待确认状态，不猜测归类。
- 可研究保存本公司账户资料，后续相同账户来源复用；按交易对手分组视图可复用本轮的缩略图与批量操作。

## 本轮边界

不增加交易字段解析、公司账户管理或按交易对手导出功能，不改变本轮收尾验收范围。
