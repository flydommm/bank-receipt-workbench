# NSIS 显示名称兼容

`installer.nsi` 基于本项目锁定的 `@tauri-apps/cli-win32-x64-msvc@2.11.4` 内嵌 Tauri 官方模板，沿用 MIT 许可（见 LICENSE-MIT）。原模板统一为 LF 后的 SHA-256：`20f4ecc730defb71f1342eaeaec4021df13be3d843abba0effe88ea5835fa079`。CLI 固定为该版本；以后升级 CLI 时须同步审阅模板差异，不能只更新依赖。

定制范围：

- 产品和快捷方式显示“银行回单工作台”，注册表卸载键、安装位置键继续使用 `PDF 精准查找`，使旧 NSIS 版本仍能被检测并读取既有安装目录。
- `com.local.pdfsearch`、`pdf-search.exe` 和应用数据目录保持原身份；未添加数据迁移或清除操作。
- 安装时只迁移指向当前安装目录 `pdf-search.exe` 的旧名快捷方式。同名新快捷方式若属于其他目标则保留；卸载只清理属于该安装的快捷方式。
- 沿用原有交互、WebView2 引导和用户明确选择的数据删除行为。实际安装/升级验证须由用户进行；编译和生成脚本检查不等同于已验证安装成功。

本版本交付 NSIS 安装器。未承诺 MSI 改名迁移路径，MSI 不作为此次交付物。
